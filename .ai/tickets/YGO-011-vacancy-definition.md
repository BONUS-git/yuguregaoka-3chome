# YGO-011 R-001 要求仕様の「空き家」が ADR-0002・ADR-0023 と食い違う
状態: done

## 目的
`.ai/reviews/0001-design-review.md` の R-001 の指摘を直します。要求仕様の §2「空き家」と FR-007・FR-074・FR-093 を、生きている ADR-0060（ADR-0002 を置き換え）と ADR-0062（ADR-0023 を置き換え）にそろえます。

## 範囲
- `.ai/requirements.md`
  - §2 用語「空き家」: 3 つの空き家（使われたことのない住所・`vacant_deleted`・`vacant_forwarded`）に書き分け、ログインしないだけでは空き家にしないこと（休眠は入居、`vacant_expired` は OQ-088）と、MVP の候補は使われたことのない住所だけで空き家を候補に戻すのは段階 3 からであることを書く（ADR-0060 の D1〜D5、ADR-0062 の D1・D3・D4）。
  - FR-007: 候補を `vacant_deleted`・`vacant_forwarded` とし、段階 3（F-16）から候補に戻すこと、`vacant_expired` は OQ-088 の答えで移行を作るときだけ候補になることを書く。区分は `[inferred]`。
  - FR-074: 転送期間が終わった旧住所は `vacant_forwarded` になって候補になり、転送と再割り当ては段階 3（ADR-0062 の D1）と書く。区分は `[inferred]`。
  - FR-093: 削除で住所はすぐ `vacant_deleted` になり、候補に戻すのは段階 3 から（MVP では戻さない）と書く。区分は `[inferred]`。
- `.ai/open-questions.md`
  - §7 の 1: OQ-079 の答えの ADR を ADR-0060 にする。
  - OQ-027 の `**ADR**:` の行: ADR-0060 だけを載せ、経緯の注記をなくす。
- 直さないところと理由
  - FR-006・FR-071: すでに ADR-0060 の流れ（休眠は入居、休眠を空き家にするかは OQ-088）で書かれ、区分は `[inferred]` なので変えない。レビューの直し方の案の「通知と休眠を経て空き家にする流れ」は、置き換えられた ADR-0002 の決定で、ADR-0060 の D3 と食い違うので採らない。
  - ADR-0002 の題とファイル名のずれ: ADR-0002 は置き換え済み（→ 0060）なので注記を足さない。生きている ADR-0060 は題とファイル名が合っている。注記を足すと、置き換えの注記を新しく足さないという決まりともぶつかる。
  - ADR の決定は変えないので、新しい ADR（0075）は作らない。マスターの判断が要る点もないので、`open-questions.md` に問いを足さない。
  - ほかの指摘は範囲外: FR-072・FR-075・§7 の 6 は R-026、D-006 は R-034、§7 の残りは R-007、休眠のあとのログインは R-028。レビューのファイルも変えない。
