# YGO-070 G-079 CI の定義で prepare.sh の段を check.sh の前に置く
状態: done
M: M1

## 取り下げ
- 取り下げを決めた ADR: ADR-0109 の D2・D4・D5（形は `.ai/gaps.md` の冒頭 `[assumed]`）。取り下げを行ったチケット: YGO-100。
- 理由: CI の定義（`.github/workflows/check.yml`）は秘書の CI の決まった形で、秘書が入れ、ジョブは `.github/` を書かない・変えない（CLAUDE.md・ADR-0109 の D2）。このチケットは変更 20261127-c384dc で範囲の外（out_of_scope）とされた。理由は、CI の定義がジョブで変えられないことだった。CI の定義に段があることの確かめは、ジョブが作れないファイルの事実なので、チケットの受け入れ確認に置かない（ADR-0109 の D4・D5）。
- 満たさないまま残した受け入れ確認: もとの受け入れ確認 1（CI の定義のファイルがあり、`sh scripts/prepare.sh` の行が `sh scripts/check.sh` の行より前にある）。G-079 は、秘書の `check.yml` を待ち、そのあとで確かめた事実の記録と文書の書き直しをするチケット YGO-101 で追う（ADR-0109 の D4・D6）。CI が緑かは M1 の達成の確認で見る。
