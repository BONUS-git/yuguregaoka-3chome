# YGO-088 G-080 実装のジョブで許すコマンドの一覧が動くのを確かめる
状態: open
M: M1
種類: 指摘の対応

## 目的
`.ai/gaps.md` の G-080 を追う。実装のジョブではコマンドを動かす道具（Bash）が拒まれ、YGO-078（`package.json` とロックファイル）とそれを待つ YGO-072・YGO-076・YGO-077 が止まっている。
秘書がジョブの実行の設定で一覧のコマンドを許したあと、実装のジョブで一覧のコマンドが動くことを確かめて記録し、`environment.md`（§5 と「マスターが用意するもの」の表の注記）・準備書 `.ai/deploy/readiness.md` §4・`.ai/gaps.md` の G-080 の「今の状態」を事実に合わせて書き直す。
ジョブが作るもの（確かめた事実の記録と、これらの文書の今の状態の書き直し）があるので、ADR-0109 の D6・D9 によりチケットにする（`.ai/gaps.md` の冒頭の例外は、ジョブが作るものが何もない行だけ。ADR-0109 の D7）。

## 仕分け 16 の K-020 の案 (c) に従わない理由
仕分け 16 の K-020 は、G-080 にチケットを切らず、理由の列の頭に `外待ち:` の句を付ける案 (c) を挙げている。
このチケットはその案に従わない。理由: 案 (c) の句で区別する点検は秘書の固定コードの変更が入るまで効かず、それまで G-080 は点検で ✗ のまま残る。
一方、一覧が動くことを確かめて `environment.md`・準備書 §4・G-080 の行の今の状態を書き直すのはジョブの仕事で、ジョブが作るものがある。
そのため、マスターの指示（M1 に向かう gaps の行にすべてチケットを置く）と ADR-0109 の D6 に従い、題に G-080 を付けたこのチケットで追う。案 (c) は ADR-0109 の「代わりの案」に選ばなかった理由とともにある。

## 依存
- 秘書がジョブの実行の設定で、`environment.md` §5 の「ジョブがコマンドを動かす権限」の一覧（Bash・`node -v`・`npm --version`・`npm_config_cache` を付けた `npm install --package-lock-only --ignore-scripts`・`sh scripts/prepare.sh`・`sh scripts/check.sh`）を許していること。
  許されるまで、このチケットの実装の変更は出さない。
- YGO-078 との順番と分け方: 同じ節（`environment.md` §5 の「ジョブがコマンドを動かす権限」）を YGO-078 も範囲（「入れたあとの状態に書き直す」）と受け入れ確認 12 で書き直すので、次のように分ける `[assumed]`。
  - このチケットが先に出る（YGO-078 を出し直すより前）。書き直すのは、Bash・`node -v`・`npm --version`・`sh scripts/prepare.sh`・`sh scripts/check.sh` の今の状態だけ。
  - YGO-078 があとに出て、npm の行（`npm_config_cache` を付けた `npm install --package-lock-only --ignore-scripts`）とロックファイルの部分・「マスターが用意するもの」の表の npm（ジョブ）の待つチケット・G-080 の行を閉じることだけを書き直す。YGO-078 の受け入れ確認 12 は、このチケットが書いたあとの文に対して確かめる。
  - このチケットは YGO-078 のファイルそのものを変えない。

## 範囲
- 実装のジョブで `node -v`・`npm --version`・`sh scripts/prepare.sh`・`sh scripts/check.sh` を動かし、返った値と結果を確かめる。
- `.ai/environment.md` §5 の「ジョブがコマンドを動かす権限」の「今の状態」を、確かめた事実（動いたコマンドと返った主版）に書き直す。
- `.ai/environment.md` の「マスターが用意するもの」の表の下の注記（待つチケットの決め方の段落）の「YGO-078 を止めているのは…Bash が拒まれること」の文を、確かめた事実に書き直す。
- `.ai/deploy/readiness.md` §4 の G-080 の箇条を、確かめた事実に書き直す。
- `.ai/gaps.md` の G-080 の行の頭の今の状態の文（「今 YGO-078 を止めているのは、実装のジョブではコマンドを動かす道具（Bash）が拒まれること」）を、確かめた事実（一覧のうち npm のロックファイルの作成だけが残る）に書き直す。行は閉じない。

## 直さないところ
- ロックファイル（`package-lock.json`）と `package.json` を作ること。YGO-078 の範囲に残す。
- G-080 の行を閉じること。閉じる条件のうちロックファイルの部分は YGO-078 の受け入れ確認 12 で満たすので、G-080 を閉じるのは YGO-078 の変更のまま。
- `.ai/gaps.md` の G-082 の行。止まった回数の記録と、閉じる条件（G-080 が閉じ、YGO-078 が `状態: done` になる）は YGO-078 の出し直しと結果にかかるので、YGO-078 の変更に残す。
- YGO-078・YGO-070・`.ai/status.md`・`.ai/triage.md`・`.github/`・`standards/`。
