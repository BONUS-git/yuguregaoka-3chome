# YGO-101 G-079 秘書の check.yml の prepare.sh の段を確かめて記録する
状態: open
M: M1
種類: 指摘の対応

## 目的
`.ai/gaps.md` の G-079 を追う（ADR-0109 の D4・D6）。CI の定義（`.github/workflows/check.yml`）は秘書の CI の決まった形で、秘書が入れる（ADR-0109 の D2）。
秘書が `check.yml` を入れたあと、`sh scripts/prepare.sh` の行と `sh scripts/check.sh` の行の有無と順を読んで確かめる。確かめた事実を記録し、段がないことを前提にした文書を今の状態に書き直す。
ジョブが作るもの（確かめた事実の記録と、文書の今の状態の書き直し）があるので、ADR-0109 の D6 によりチケットにする（`.ai/gaps.md` の冒頭の例外は、ジョブが作るものが何もない行だけ。ADR-0109 の D7）。

## 依存
- 秘書が、プロジェクトに決まった形の `.github/workflows/check.yml` を入れていること（ADR-0109 の D2）。入るまで、このチケットの実装の変更は出さない。
- このチケットは `.github/` を書かない・変えない（CLAUDE.md・NFR-091）。読むだけにする。CI の定義に段があることは、このチケットの受け入れ確認に入れない（ADR-0109 の D4）。受け入れ確認は、`.ai/` の中の記録と書き直しだけを見る。
- 読んだ結果、決まった形に `sh scripts/prepare.sh` の段がないか、`sh scripts/check.sh` の段より後ろにあるときは、G-079 の行を閉じない。確かめた事実を G-079 の行・`environment.md` §5・準備書に書き、段を前に置くことを秘書に伝える（ADR-0109 の D2。マスターへの要回答にはしない）。G-079 のあとの記録（秘書が段を置いたあとで読み直して閉じる）は、題に G-079 を付けた続きのチケットに渡し、このチケットは `done` にする `[assumed]`。これは ADR-0109 の D6・D8 から導いた暫定で、D4 の決定（G-079 は YGO-101 で追い、受け入れ確認は `.ai/` の中の記録と書き直しだけを見る）は変えない: 読み直して閉じる仕事は、外の作業（秘書が段を置く）を待ったあとにジョブが作るものなので D6 によりチケットで追う。このチケットの記録と書き直しが済めば、その仕事を受け持つ open のチケットはほかにない（D8）ので、題に G-079 を 1 つ付けた新しいチケットを切る。

## 待っているもの
- 今の状態: レポジトリに `.github/` がなく、秘書の `check.yml` はまだ入っていない。読む相手がないので、このチケットの範囲はどれもまだ進められない。そのため `状態: open` のままにする。
- 待つもの: 秘書がプロジェクトに決まった形の `check.yml` を入れること（ADR-0109 の D2）。入ったあと、このチケットを実装のジョブに出す。
