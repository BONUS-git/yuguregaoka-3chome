# YGO-074 R-070 M0 の土台を M1 のチケットに混ぜ範囲が曖昧
状態: open
M: M1

## 目的
`reviews/0004-phase-evaluation-2026-11-27.md` の R-070（区別: 中、評価の ID: E-024）を直す。
YGO-062・YGO-065 は M0 の残り（時計・メールのアダプタ・キュー・2 プロセスの骨組み・環境変数の読み込み など）を「M0 の別のチケット」とするが、そのチケットはない。M1 の登録の TC はそれに依存する。M1 の TC に要る M0 の部品を、`M: M1` のチケットとして切る。

## 依存
- このチケット（チケットを切ること）は、YGO-062 の done を待たない。切ったチケットの実装は YGO-062 の done を待ち、YGO-065 のあとに並べる。

## M1 の TC が使う M0 の部品
`tests/test-plan.md` の種類「ジョブ」は、worker のジョブ J14・J18 を差し替えた時計で動かす。J18 はメールのアダプタを worker の環境変数 `MAIL_ADAPTER` で選ぶ（`async.md` §4 J18、`environment.md` §8.1）。そのため、M1 の TC が使う部品は次のとおり。

| 部品 | 使う M1 の TC |
|---|---|
| 差し替えられる時計 | TC-016・TC-017 |
| `jobs` のキュー（積むこと） | TC-017・TC-019 |
| worker のジョブの実行（2 プロセスの骨組みのうち worker が J14・J18 のハンドラを動かす部分） | TC-017（J14）・TC-020（J18） |
| 環境変数の読み込み（`MAIL_ADAPTER` の選択） | TC-020 |
| モックのメールのアダプタ | TC-020 |

## 範囲
- 次の 5 枚の新しいチケット（`状態: open`・`M: M1`）を切る。
  1. 時計（差し替えられる時計。TC-016・TC-017 が使う）
  2. `jobs` のキュー（TC-017・TC-019 が使う）
  3. 環境変数の読み込みと `MAIL_ADAPTER` の選択（TC-020 が使う）
  4. モックのメールのアダプタ（TC-020 が使う）。3 に依存する
  5. worker のジョブの実行（worker のプロセスが `jobs` から J14・J18 を取ってハンドラを動かす。TC-017・TC-020 が使う）。1・2・4 に依存する
- 5 枚の「依存」の節に、YGO-065 のあとに並べることと、上の互いの依存の順（1・2・3 → 4 → 5）を書く。
- `.ai/tickets/YGO-062-m1-test-harness.md` と `.ai/tickets/YGO-065-m1-resident-address-schema.md` にある「M0 の別のチケット」「別のチケット」のうち、時計・メールのアダプタ・キュー・2 プロセスの骨組み・環境変数の読み込みを指す記述を、切ったチケットの番号に直す。
- YGO-062 の直さないところの「`scripts/dev-db.sh`・時計・アダプタ・2 プロセスの骨組み・キュー・`APP_ENV` と環境変数の読み込み」の 1 行を分ける。時計・アダプタ・キュー・worker のジョブの実行・環境変数の読み込みには切ったチケットの番号を書く。残る `scripts/dev-db.sh`（開発の DB の台本。`check.sh` は使い捨ての PostgreSQL を使い、TC はこの台本を使わない）と、`APP_ENV` の起動の検査（`staging`・`production` で偽の鍵か `CLOCK_OFFSET` があれば起動に失敗する。M1 の TC はどれも確かめない）は、M1 の TC が使わないため M1 のチケットにせず、使う TC のチケットを切るときに扱うと書く `[assumed]`。YGO-062 の範囲の M0 の残りの列挙・§3.2 の 2 以降（`dev-db.sh`・`.local/`）の行・受け入れ確認 12、YGO-065 の直さないところの同じ列挙も、同じように分ける。
- 切ったチケットを `.ai/INDEX.md` に載せる。

## 直さないところ
- 時計・キュー・環境変数の読み込み・アダプタ・worker のジョブの実行の実装そのもの: 切ったチケットで 1 枚ずつ。
- M1 の TC が使わない M0 の残り（`scripts/dev-db.sh`・`APP_ENV` の起動の検査）: 使う TC のチケットを切るときに扱う。
- 使い捨ての PostgreSQL: YGO-076（YGO-073 で切ったチケット）で扱う。
