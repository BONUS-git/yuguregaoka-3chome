# YGO-032 K-006 R-012 J1 が尽きた回の pending の手紙を届ける
状態: done
M: M1

## 目的
`triage.md` 仕分け 3（最新の回）の「今決める」K-006（出どころ R-012）を決める。
J0 が J1（締め切り）を積むのは配達回が `pending` のときだけで、回が `running` になったあとに J1 の再試行が尽きると、残った `pending` の手紙はどの工程にも拾われず、送った人には「投函済み」と見えたままになる。
R-012 の直し方の案（`running` の回で `pending` が残っていれば J0 が J1 を積み直す）に沿って `[assumed]` で決める。R-012 はマスターの判断を「不要」としており、新しい要回答は 0 件。

決めたこと（ADR-0094 の D8）:
- 締め切りが済んだとは、その回に `pending` の手紙がなく、かつその回の審査待ちの投稿（`awaiting_review`）のすべてに `moderation_queue` の行があること。手紙がすべて `scheduled` になったあとや手紙のない回で J1 が尽きても、投稿が審査されないまま残らない。
- J0 は `running` の回について、`failed` の判断（D5）と持ち越しの打ち切りの判断（D4）のあとに、締め切りが済んでいなければ J1 を積み直し、締め切りが済むまで J2〜J5（M5 からは J16 も、休刊の J3 も）を積まない。
- J1 は区切りごとのトランザクションのはじめに配達回の行を `FOR UPDATE` で取る。`running` で打ち切りの前なら残りの `pending` の手紙を `scheduled` にし、`done`・`skipped`・`failed` か打ち切りのあとなら何も書かない。
- 積み直した J1 は、審査キューに同じ投稿の行を重ねない（`WHERE NOT EXISTS`）。一意制約は K-007（R-013）で決める。
- 打ち切りまでに締め切りが済まなければ、J6 が残りの `pending` の手紙を `pending` のまま、審査待ちの投稿を `awaiting_review` のまま次の受付中の配達回に移し、移し先の回の J1 が手紙を `scheduled` にして投稿を審査キューに入れる。

D8 で ADR-0092 の D2（審査の開始の条件）に「締め切りが済んだ」が加わり、前の決定の一部が変わる。ADR-0092 の決定（D1〜D7）を同じ番号で引き継ぎ、D8 を足した ADR-0094 で ADR-0092 を丸ごと置き換える。
