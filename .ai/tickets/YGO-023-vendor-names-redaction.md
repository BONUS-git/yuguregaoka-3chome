# YGO-023 K-001 事業者の名前と価格を公開の文書から外す（R-024）
状態: done
M: M1

## 目的
条件 4 を進める変更です。`.ai/triage.md` の最新の回（仕分け 2、2026-11-25）に、まだ決めていない「今決める」が残っているので、ユースケース図は作らず、番号のいちばん若い K-001（`.ai/reviews/` の R-024、重大）を決めます。

公開の文書に、契約先になりうる外部 LLM の事業者の名前（サービス・モデル・製品の機能の名前）と、日付つきの料金表が載っていました。
載せてよいかは公開の範囲の問いで、マスターにしか決められません。そこで要回答の OQ-091（`- 止める M: M1`）を立て、暫定（載せない。一般の呼び名と変数の式で書く）で文書と ADR-0031 を直します。

決めたこと（`[assumed]`）:
- 書かないもの: 契約先になりうる事業者と、そのサービス・モデル・製品の機能の名前、およびその料金。「外部の LLM サービス」「軽量のモデル」「上位のモデル」「一括処理（バッチ）の API」「推論の量は最小の設定」と、変数 `P_in`・`P_out`（100 万トークンあたりの入力・出力の単価）の式にする。
- 今までどおり書くもの: 言語・DB・ライブラリ・ツールの名前。
- 費用の見積もりのトークンの量は変えない。

## 直さないところと理由
- ADR-0031 は置き換えない: D1〜D4 の決定は変わらず、名前を書かないだけ。「名前を書かない」を新しい ADR で決めると、要回答（OQ-091）の答えを前提にした決定になる。ADR-0086 は作らない。
- `.ai/reviews/`・`.ai/triage.md`: 指摘と仕分けの記録で、秘書のジョブが扱う。R-024 を閉じるのは OQ-091 の答えのあと。
- `.ai/status.md`: 秘書が書く。
- `.ai/diagrams/`・`.ai/INDEX.md`: ユースケース図は今決めるが残るので作らない。図が増えないので地図も変わらない。
- `.ai/environment.md`・`.ai/mvp.md`: 事業者の名前と料金を含まない。
- git の履歴: 過去のコミットの書き換えはジョブの範囲の外。するかどうかは OQ-091 でマスターに聞く。
- ADR-0085 などの `$1`: SQL のプレースホルダで、料金ではない。
- テストのコード・`scripts/check.sh`: 足さない。確かめるのは文書だけ。
