# YGO-030 OQ-092 の答えを反映し、外部 LLM の名前と料金を CLAUDE.md の決まりの例外にする
状態: done
M: M1

## 目的
マスターが OQ-092（OQ-091 の答えと CLAUDE.md の決まりのどちらを優先するか）に「OQ-091 の答えを優先する。外部 LLM の事業者・モデルの名前と料金に限って載せる」と答えた（2026-11-25）。
暫定の (a) のとおりなので ADR は足さず、OQ-092 を決定に移し、ADR-0086 の D6 と関係する文書を決定の書き方に直す。
ADR-0086 の D6 が例外にしていなかった NFR-083（コミットに実在の団体を含めない）も、同じ範囲の例外にする。新しい要回答は 0 件。

例外の範囲は 1 つにそろえる `[assumed]`:
- 載せる: 外部 LLM の事業者の名前（Anthropic）・モデルの名前（Claude Haiku 5.5、`claude-haiku-5-5` など）・日付つきの料金。事業者の名前に一般の語を付けただけのサービスの名前（Anthropic API）は事業者の名前として扱う。
- 載せない: 製品の機能や API の項目の名前。役割の名前（一括処理（バッチ）の API・構造化出力・推論の量の設定）で書く。

- `architecture.md`・`environment.md`・`mvp.md`・`gaps.md`・`INDEX.md`・図: 事業者・モデルの名前だけを書いており、範囲の中で変わらない。OQ-092 を指していない。
- ADR-0031: 置き換え済みの ADR で、今の決定ではない。
- `reviews/`・`triage.md`: 指摘と仕分けの記録で、秘書のジョブが扱う（R-055 を閉じるのは秘書の見直し）。
- `status.md`・CLAUDE.md・`standards/`: 変更禁止。
- `scripts/check.sh`・テスト: 確かめるのは文書だけで、足さない。
- 新しい ADR: 答えが暫定のとおりなので作らない。
