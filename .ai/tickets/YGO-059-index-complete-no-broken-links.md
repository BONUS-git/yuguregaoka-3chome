# YGO-059 地図（INDEX.md）にすべての文書と図を載せ、リンクの切れをなくす
状態: done
M: M1

## 目的
条件 6 のために、参照の地図 `.ai/INDEX.md` に `.ai/` の下のすべての文書と図を載せ、地図のどのパスも実在するファイルを指すようにする。
置き換えた ADR は消さず、地図の各 ADR の行で状態（`採用` か `置き換え（→ NNNN）`）がわかるようにする。

## 確かめた事実
- `.ai/` の下のファイルは、このチケットを除いてどれも `INDEX.md` にバッククォートのパスで載っている（ADR 0101・0102、`reviews/0003`、YGO-051〜058、`triage.md` を含む）。載っていなかったのはこのチケットだけ。
- `INDEX.md` のバッククォートの `.ai/…` のパスは、どれも実在するファイルかディレクトリを指す。Markdown のリンク（`](…)`）はない。
- ADR 102 件の 3 行目の状態: `置き換え（→ NNNN）` が 40 件、`採用` が 62 件。
- 知りたいことの表が番号で指す ADR（0033・0061・0080・0083・0084・0087・0088・0090・0091・0093・0094・0095・0096・0097・0099・0100・0102）は、どれも `採用`。直すところはない。
- `check:consolidation` は秘書の側の点検で、レポジトリにも `scripts/check.sh` にもない。

## 範囲
- このチケット。
- `.ai/INDEX.md`: チケットの一覧に 1 行。ADR の一覧の各行（`README.md` を除く）の末尾に ` — 採用` か ` — 置き換え（→ NNNN）` を付け、節の説明の行を「各行の末尾は状態（各ファイルの 3 行目と同じ）」にする（レビューの一覧と同じ ` — ` の書き方）`[assumed]`。
- `scripts/check.sh`: 地図の点検を `check: ok` の前に足す `[assumed]`。`.ai/` の下のファイルが地図に載っていない・地図のパスが実在しない・ADR の行の末尾の状態がその ADR の 3 行目と合わない、のどれかで失敗する。ネットワークは使わず、POSIX sh だけで動く。

- 地図のほかの節と、`.ai/` のほかの文書の中身: 食い違いはなかった。この変更は地図のパスと状態の書き方だけ。
- 新しい ADR・OQ・要回答は 0 件（決定の中身を変えない）。
