## §1 デプロイはしない

- **自律の段階は L0**: 秘書はデプロイ・IaC の適用・クラウドの契約・アカウントの作成・ドメインの取得をしない（NFR-071・NFR-072、`environment.md` §10.1）。費用の発生を伴う操作はマスターの事前承認を得る（NFR-080）。
- この文書は実際の値を書かない。アカウントの ID・プロファイル名・ドメイン・鍵の場所・事業者の名前は、種類と状態だけを書く（公開レポジトリ）。
- **配布の項目は置かない**: Web アプリ（ADR-0009。通知は Web Push、ADR-0076）で、ネイティブアプリではないため、ストアへの配布と署名の項目はない。
- §2 の表の状態の言葉は次の 4 つだけ。

| 状態 | 意味 |
|------|------|
| 未確認 | まだ設計も確かめもしていない |
| 秘書が決めた | 秘書が ADR か正本の文書で設計を決めた（値は入れていない） |
| マスターの用意が要る | 費用・契約・公開の範囲にかかわり、マスターが決めるか用意する（OQ で持ち越し） |
| 用意済み | デプロイに使える形で用意されている |
