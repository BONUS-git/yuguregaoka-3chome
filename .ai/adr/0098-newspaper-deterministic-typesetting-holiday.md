# 0098 — 新聞はテンプレートで決定的に組み、組版の失敗は休刊

- 状態: 採用
- 日付: 2026-11-26

ADR-0007 を丸ごと置き換える。`reviews/0001-design-review.md` の R-027（YGO-041）。
ADR-0007 の生きている決定（テンプレートでの決定的な組版・組版の失敗は休刊・紙面の構成の案）を、今の新聞の決定（ADR-0055・ADR-0054・ADR-0035）に合わせてこの ADR に移した。
新しい要回答はない。

## 背景

FR-033 では組版バッチが朝刊・夕刊を組み、FR-037・NFR-022 では組版の冪等性が求められている。NFR-030 は組版に失敗した回の扱いを求めている。
新聞の記事の文字は LLM が作り、組版はサーバーで行う（OQ-051 の答え、ADR-0055 の D7）。投稿の記事は LLM の見出しだけで、まとめは書かない（OQ-074 の答え、ADR-0054 の D9）。
ADR-0007 は、これらの決定に合わない文と経緯の注記が残っていたので、生きている決定だけをこの ADR にまとめる。

## 決定

1. **D1 組版はテンプレートで決定的に行う**: 新聞の組版は、組版エンジン（C6、ADR-0011）がテンプレート（静的なレイアウト定義）で決定的に行う。
   入力は `newspaper_articles` に保存した記事の文字と素材で、組版（J3・J8）のやり直しでは LLM を呼ばない。記事の文字を誰が作り何を保存するかは ADR-0055 の D7 のとおり。
2. **D2 組版の失敗は休刊**: 組版に失敗した回は「休刊」とし、その配達回は紙面を届けない。前の紙面は流用しない（NFR-030）。
   郵便受けには紙面の代わりに休刊の印と手紙が届き、新聞の通知「新聞が配達されました！」も送る（ADR-0035 の D11）。休刊の回の紙面はバックナンバーにも出さない。
3. **D3 LLM の失敗では休刊にしない**: LLM の失敗・打ち切り・検査に外れた出力では、記事を決まった形（`written_by = 'template'`）で組み、休刊にしない（ADR-0055 の D8）。
4. **D4 届け先と版**: 新聞は、その便に手紙があるかにかかわらず全住民の郵便受けに届ける（07:00 / 17:00、ADR-0035）。
   紙面は組ごとの版で、住民は 1 回の配達につき 1 つの版を受け取る（ADR-0055 の D1〜D3）。
5. **D5 紙面の構成（案）** `[assumed]`:

   | 面 | 内容 |
   |----|------|
   | 1 面 | 掲示板の承認済みの投稿（カテゴリ別）。投稿の本文はそのまま投稿の枠に入れ、LLM の見出しを枠の外に置く。まとめは書かない（ADR-0054） |
   | 2 面 | 商店街・団体からのお知らせ（段階 3 以降） |
   | 外のニュースの面 | 取り込んだ外のニュースの記事（LLM の見出しと文、ADR-0055 の D6・D7。配信元は OQ-060 で、それまではテストの偽の記事だけ） |
   | 興味の面 | 版の興味に結び付けた記事（興味の版だけ。共通の版にはない。ADR-0055 の D3） |
   | 折込 | 住民募集・イベント募集投稿 |

## 理由

- D1: LLM の出力を保存してから決定的に組むことで、組版のやり直しが同じ紙面になる（FR-037・NFR-022）。組版は LLM なしでテストできる（NFR-063。文章アダプタはテストではモック）。
- D2: 途中まで組んだ壊れた紙面を届けないため。前の紙面を流用すると古い情報を届け、住民を誤解させる。
- D3: 新聞を全住民に届けること（ADR-0035）を LLM の失敗で止めないため（ADR-0055 の理由）。
- D4・D5: ADR-0035・ADR-0055・ADR-0054 の理由のまま。

## 代わりの案（選ばなかった理由）

- **紙面全体を LLM に組ませる・組版のたびに LLM を呼ぶ**: 冪等性を保てず、作り話を紙面に出すおそれがある。LLM は公開してよいかを決めない（NFR-011・ADR-0005）。
- **組版失敗時に前の紙面を流用する**: 古い情報を届け、住民を誤解させる。
- **ADR-0007 を採用のまま、注記を足す**: 経緯の注記が決定の文に重なって読みにくく、まとめを書く文が ADR-0055 の D7・ADR-0054 の D9 と食い違うまま残る。

## 決めていないこと

- 外のニュースの配信元（OQ-060、持ち越し）・新聞の LLM のモデルとプロンプト（OQ-062、持ち越し）。ADR-0055 のとおり。

## 影響

- ADR-0007: 状態を `置き換え（→ 0098）` にした。ADR の README の一覧・`.ai/INDEX.md`。
- `open-questions.md` の OQ-020・OQ-021（ADR の欄）・D-004、`requirements.md`（FR-036・NFR-030）・`architecture.md`・`async.md`・`db.md`・`api.md`・`environment.md`・`roadmap.md`: 今の決定の参照を ADR-0007 からこの ADR に直した。同じ箇所で並べていた置き換え済みの ADR-0039 の参照（`architecture.md` §5 の休刊・`api.md` の紙面の API・`roadmap.md` の M5）は ADR-0055 にした。
- `mvp.md` の ADR-0007 の参照はこのジョブでは変えない（`mvp.md` は秘書が書く）。その参照はこの ADR として読む。
- 番号のある決定の参照は ADR-0007 になかったので、ほかの文書の参照の意味は変わらない。
