# 0046 — 新聞の LLM の文に「AI が書いた文」の印を付けない（規約は確かめる）。住民の掲示板の投稿の本文は書き換えずにそのまま載せ、LLM が書くのは生成部分だけにし、LLM の文を住民本人の文に見せない

- 状態: 置き換え（→ 0054）
- 日付: 2026-11-20

## 背景

OQ-051 の答え（ADR-0039 の D7）で、新聞の記事の文字（見出し・まとめ・外のニュースの記事）は LLM が作ると決まった。
答えには LLM が書いた文の扱いが書かれていなかったので、`open-questions.md` の OQ-061 でマスターに次の 2 点を聞いていた。
(1) LLM が書いた文を、紙面でどう示すか（例: 記事ごとに「AI が書いた文」の印を付ける・紙面の欄外にまとめて書く・示さない）。
(2) 住民の掲示板の投稿の本文を、LLM が要約したり書き直したりして載せてよいか。よい場合、投稿した住民に知らせるか・断れるか。
暫定は、投稿の本文は書き換えずにそのまま載せ、LLM が書いた見出し・まとめ・外のニュースの記事に「AI が書いた文」の印を付ける（ADR-0039 の D9）だった。

2026-11-20、マスターが OQ-061 に次のとおり答えた（原文）。

> １：示さなくて良い。規約次第なので、要確認。
>
> ２：住民の掲示板の投稿本文は、書き換えずにそのまま載せる。LLMが手を加えるのはあくまでニュース記事などの生成部分のみ。住民の生の声を勝手に加工して、あたかも本人が書いたように見せることはしない。

答えから読み取れることと、読み取れないことを分ける。

| 答え | 読み取れること（決定） | 読み取れないこと（新しい OQ） |
|---|---|---|
| 1 | 紙面で LLM の文であることを示さない（記事ごとの印も、欄外のまとめての記載も置かない） | 「規約次第なので、要確認」: どの規約が示すことを求めるか（J16 に使う LLM のサービスの規約、外のニュースの配信元の規約）・求めたときの示し方 → OQ-073（持ち越し） |
| 2 | 投稿の本文は書き換えずにそのまま載せる。LLM が手を加えるのはニュース記事などの生成部分だけ。LLM の文を住民本人が書いたように見せない | 住民の投稿を素材にした記事で、LLM が見出しとまとめを書いてよいか（それも「生成部分」か、紙面には投稿の本文だけを載せるか） → OQ-074（要回答）。暫定は D5 |

「規約」を外部のサービス（LLM のサービス・外のニュースの配信元）の規約と読むのは秘書の読み方。この街の利用規約の意味だったら、OQ-073 でマスターに聞き直す。
答え 2 は、もとの質問 (2) の「よい場合」に当たらない（書き換えない）ので、投稿した住民に知らせるか・断れるかは問いとして残らない。

答えは、ADR-0039 の D9 の暫定（LLM の文に「AI が書いた文」の印を付ける）を置き換え、D9 の「投稿の本文は書き換えない」を決定にする。

## 決定

区分は ADR-0024 の決定 5 に従う。

1. **D1 印を付けない**（答え 1、`[inferred]`）: 紙面（J3 のテンプレート）は、LLM が書いた見出し・まとめ・外のニュースの記事に「AI が書いた文」の印を付けない。紙面の欄外にまとめて書くこともしない。
2. **D2 規約を確かめる**（答え 1「規約次第なので、要確認」、秘書の判断）: 新しい問い OQ-073（持ち越し）にする。
   - 確かめるもの: J16 に使う LLM のサービスの規約（暫定の選定は ADR-0031。モデルは OQ-062）と、外のニュースの配信元の規約（配信元は OQ-060 と一緒に）。
   - 時期: 本番の文章アダプタを作る前（デプロイと契約の承認、NFR-080 の前）に、秘書が規約を読み、結果をマスターに出す。M5 とテストはモックの文章アダプタなので、それまで作業は止まらない。
   - 規約が AI の文であることを示すよう求めるなら、示し方はマスターに聞く（倫理と公開の範囲）。
3. **D3 `written_by` は残す**（秘書の判断）: `newspaper_articles.written_by`（llm / template）は、決まった形になった記事の割合を見張る（`async.md` J16 の監視・`security.md` §7.1）のに使うので残す。紙面には出さない。
   OQ-073 で印が要ることになっても、この列で LLM の文を見分けられるので、表を変えずに済む。
4. **D4 投稿の本文は書き換えない**（答え 2、`[inferred]`）: 住民の掲示板の投稿の本文は、`board_posts.body` をそのまま載せる。要約・書き直し・言い換え・切り詰めをしない。
   ADR-0039 の D9 の暫定と同じ中身で、決定にする。
5. **D5 LLM が書くのは生成部分だけ**（答え 2、`[inferred]`）: LLM（J16）が書くのは、生成部分（外のニュースの記事の文と、その見出し・まとめ）だけで、住民の投稿の本文には手を加えない。
   - **（OQ-074 の暫定）** 住民の投稿を素材にした記事の見出しとまとめも、新聞が書く「生成部分」と読み、LLM が書く（秘書の読み方。暫定）。
     住民の言葉を LLM がまとめてよいかは構想の意図と倫理にかかわるので、マスターに聞く（OQ-074、要回答）。M5 とテストはモックの文章アダプタなので作業は止まらない。M5 の前（OQ-062 でプロンプトを決める前）に答えを確かめる。
   - 答えが「書かない（紙面には投稿の本文だけを載せる）」なら変わる箇所: `async.md` §4 J16（投稿の素材を LLM に渡さない・投稿の記事を作らないか決まった形にする）と J3（投稿の枠の見出しを決まった形にする）、
     `db.md` `newspaper_articles`（投稿の素材の行の `body`・`written_by`）、`security.md` §5.3・T-20、`roadmap.md` の A-17 (6)、FR-111、この ADR の D5・D6、OQ-062 のプロンプトの条件。
6. **D6 LLM の文を本人の文に見せない**（答え 2「あたかも本人が書いたように見せることはしない」、秘書の判断）:
   - 紙面のテンプレートは、投稿の本文を 1 つの枠（投稿の枠）に入れ、その枠には `board_posts.body` だけを入れる。LLM の見出し・まとめは枠の外に、新聞の文として置く。
   - まとめを住民の言葉として書かせない（一人称で本人になりかわる・本人の発言として引用の形にする、をしない）ことを、OQ-062 でプロンプトを決めるときの条件にする。
7. **D7 段階**: M5 の中身は変わらない（印を描かないだけ）。受け入れ確認の A-17 (6) を、投稿の本文がそのまま載ること・投稿の枠に LLM の文が入らないこと・印がないこと、に直す。
8. **D8 要求の区分**: FR-111 を直す。`[inferred]`（マスターの答え OQ-061（2026-11-20）より）。

## 理由

- D1 は、答え 1「示さなくて良い」による。
- D2 は、答え 1「規約次第なので、要確認」による。規約は外部のサービスの条件で、本番のアダプタを作るまでは使わないので、持ち越しにして本番の前に確かめる。規約が示すことを求めたときの示し方は、住民に見せる紙面の形で、構想の意図にかかわるのでマスターに聞く。
- D3 は、印を付けないこととデータを持つことは別で、見張りに要り、規約の答えで印が要ることになったときに作り直しが要らないため。
- D4・D5 は、答え 2 による。ただし D5 のうち、住民の投稿の見出しとまとめを「生成部分」に含めるかは答えから読み切れず、住民の言葉を LLM がまとめること自体の可否は構想の意図と倫理にかかわるので、暫定にしてマスターに聞く（OQ-074）。
- D6 は、答え 2 の「あたかも本人が書いたように見せることはしない」を紙面の形で守るため。印を付けない（D1）ので、どの文が住民の文かは置き場所で分かるようにする。枠に入れるものを `board_posts.body` だけに決めると、テストで確かめられる（A-17 (6)）。

## 代わりの案（選ばなかった理由）

- **記事ごとに「AI が書いた文」の印を付ける（ADR-0039 の D9 の暫定のまま）**: 答え 1「示さなくて良い」と食い違う。規約が求めるなら OQ-073 でマスターに聞き直す。
- **紙面の欄外にまとめて書く**: 同じく答え 1 と食い違う。
- **投稿の本文を LLM で要約・書き直して載せる**: 答え 2「書き換えずにそのまま載せる」と食い違う。
- **`written_by` を消す**: 見張りに使っており、OQ-073 で印が要ることになったときに LLM の文を見分けられなくなる。
- **規約を今すぐ読んで決める**: 本番の LLM のモデル（OQ-062）と外のニュースの配信元（OQ-060）が決まっておらず、読むべき規約が定まらない。

## 決めていないこと

- 規約が AI の文であることを示すよう求めるか、求めるならどう示すか（OQ-073、持ち越し。本番の文章アダプタを作る前に秘書が規約を読む）。
- 住民の投稿を素材にした記事で、LLM が見出しとまとめを書いてよいか（OQ-074、要回答。暫定は D5 のとおり書く。M5 の前に答えを確かめる）。
- 紙面に投稿者（ニックネームなど）を出すか: この答えでは決めない（今の文書のまま）。
- 外のニュースを LLM で要約・書き直してよいか（配信元の利用の条件）: OQ-060（持ち越し）のまま。
- 住民への説明（利用の案内に、新聞の文を LLM が書くことを書くか）: OQ-032（持ち越し）のまま。
- プロンプトの中身（D6 の条件を含む）・長さの上限: OQ-062（持ち越し）。
