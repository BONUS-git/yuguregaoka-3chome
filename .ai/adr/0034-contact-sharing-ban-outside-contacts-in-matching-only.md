# 0034 — 共有を禁止する「連絡先」は街の外の連絡先だけ。禁止はマッチングの中だけで、掲示板・手紙には及ばない

- 状態: 採用
- 日付: 2026-11-19

## 背景

OQ-001 の答え（2026-11-19、ADR-0024）で「個別に連絡先の共有などは絶対禁止にする予定」と決まり、
住民どうしが個別に連絡先を共有することを禁止した（FR-101、ADR-0024 の D3）。
マッチングの参加の登録と提案には、街の外の連絡先を入れる欄を設けないことにした。
「連絡先」の範囲（街の外の連絡先だけか、街の住所も含むか）と、禁止の範囲（マッチングの中だけか、手紙・掲示板にも及ぶか）は
答えに書かれておらず、`open-questions.md` の OQ-041 でマスターに聞いていた。
暫定は「禁止はマッチングの中だけ。掲示板の審査は今のまま（ADR-0005）。手紙の審査は ADR-0026 のとおりで、本番のルール表に手紙に当てる項目を置かない」だった。

2026-11-19、マスターが OQ-041 に次のとおり答えた（原文）。

> 街の外の連絡先のみ。禁止はマッチングの中のみ。掲示板・手紙への禁止は及びません。

## 決定

1. **D1 「連絡先」は街の外の連絡先だけ**（マスターの答え）: 禁止する「連絡先」は、街の外の連絡先
   （メールアドレス・電話番号・他のサービスのアカウント・実在の住所など）だけとする。
   街の住所（夕暮ヶ丘三丁目の住所）は含まない。成立後は街の中の手紙でやり取りする（FR-067・ADR-0024 の D2）は変わらない。
2. **D2 禁止はマッチングの中だけ**（マスターの答え）: 禁止が効くのはマッチング（参加の登録と提案）の中だけで、
   掲示板と手紙には及ばない。
3. **D3 掲示板・手紙の審査は変えない**（答えから読み取ったもの）: ルール表（`security.md` §5.1）に、FR-101 を理由にした項目
   （連絡先の共有の禁止として街の外の連絡先を止める項目）は置かない。ほかの理由（個人情報の保護など）で電話番号・メールなどを止める項目を
   置くかは、この決定の範囲の外とする。掲示板の審査（ADR-0005）・J2 の対象・手紙の審査（ADR-0026）は今のままとする。
   手紙で止める内容は OQ-052（もとは OQ-043 の 1 点目で、2026-11-19 に ADR-0036 で移った）で、この ADR は FR-101 を理由に手紙の項目を足さない。
   （追記 2026-11-20）OQ-052 → 決定（ADR-0040）。手紙に当てる項目はスパム・外部リンク・成人向けの言葉で、メールアドレスと電話番号は外部リンクに含めない（この D3 とそろえた）。
   偽の連絡先を含む手紙は今までどおり届く。
4. **D4 変わらないこと**: マッチングの参加の登録と提案に街の外の連絡先の欄を設けない（ADR-0024 の D3）、
   恋愛のカテゴリを設けない（ADR-0024 の D1）、年齢条件を置かない（ADR-0027）、成立後は街の中の手紙でやり取りする（FR-067）、
   ブロック・通報・審査と連絡先の共有の禁止は、OQ-063 の答えまでは、年齢に関係なくすべての住民に同じに効く（ADR-0027。ADR-0041 の D1 で年齢で変えることにした）。
5. **D5 マッチングの中での守り方の細部は OQ-050**（持ち越し）: 答えは、マッチングの中で禁止をどう守るかを
   「欄を設けない」のほかには書いていない。(1) 参加の登録に自由記述の欄を設けるか、設けるならそこに書かれた街の外の連絡先をどう扱うか、
   (2) 成立後に最初の手紙を出す方法（提案に相手の街の住所を載せるか）は、S3-3 のマッチングのアルゴリズムの ADR（FR-066）で決める。

## 理由

- D1・D2 は、マスターの答え（上の原文）による。構想の意図はマスターにしか決められない。
- D3 は、答えが「掲示板・手紙への禁止は及びません」なので、FR-101 を理由に掲示板・手紙で連絡先を止める項目を置く理由がないため。
  答えは FR-101 の範囲だけを決めており、ほかの理由で個人情報を止めるかは決めていない。手紙で止める内容は別の問い（OQ-052）で、その答えを前提にしない。
- D5 は技術と設計で決められることで、マッチングの仕組みを決める ADR と一緒に決めるのが自然なため（持ち越し）。
  デプロイも段階 3 の実装もまだなので、今は要らない。

## 代わりの案（選ばなかった理由）

- **街の住所も「連絡先」に含める**: 答え（街の外の連絡先のみ）と食い違う。成立後に手紙でやり取りできなくなる。
- **掲示板・手紙の審査にも FR-101 を理由に街の外の連絡先の項目を置く**: 答え（掲示板・手紙への禁止は及ばない）と食い違う。
- **マッチングの自由記述の扱いや最初の手紙の出し方をここで決める**: 答えに書かれておらず、
  マッチングのアルゴリズム（FR-066）と一緒に決めるもの。OQ-050（持ち越し）にした。

## 決めていないこと

- マッチングの中での守り方の細部（自由記述の欄と、成立後に最初の手紙を出す方法）: OQ-050（持ち越し、S3-3 のアルゴリズムの ADR で決める）。
- 手紙で止める内容と、止めた手紙の閲覧: OQ-052 → 決定（2026-11-20、ADR-0040）。この ADR では変えない。
  通報された手紙をモデレーターが確かめることは OQ-043 → 決定（2026-11-19、ADR-0036）。
- 禁止に違反した住民への処置: OQ-048（持ち越し、ADR-0032）。
