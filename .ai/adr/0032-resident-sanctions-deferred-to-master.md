# 0032 — 違反した住民への処置の内容は、マスターが後で決める。決まるまで処置を実行する手段は作らない

- 状態: 採用
- 日付: 2026-11-19

## 背景

`requirements.md` の FR-081 と F-08・F-14 は通報とモデレーションを定めるが、通報が認められたときに住民に対して行う処置
（警告・投稿の停止・アカウントの停止など）の内容は決めていなかった。
`open-questions.md` の OQ-037 で、処置の内容・重さ・手続き（住民への通知・異議申し立ての可否）をマスターに聞いていた。
暫定は「処置の種類は未定。モデレーターが `moderation_actions` に処置を記録する仕組みは設計しておく。処置の実行手段は回答後に実装する」だった。

2026-11-19、マスターが OQ-037 に次のとおり答えた（原文）。

> 処置の内容は未定（後ほど決定）

## 決定

1. **D1 処置の内容はマスターが後で決める**（マスターの答え）: 違反した住民への処置の種類・重さ・住民への通知・異議の手続きは、
   この ADR では決めない。残る問いは OQ-048（持ち越し）とし、処置を実行する手段を作る前、遅くともデプロイの前にマスターに聞く。
2. **D2 決まるまで、住民への処置を実行する手段は作らない**（秘書の判断）:
   - 住民を停止・警告する API・CLI・DB の列や状態を置かない。
   - 管理者の通報への操作（`POST /api/v1/admin/reports/{id}/actions`）は approve / reject / dismiss のまま。
     `moderation_actions.action` の値は approve / reject / dismiss / view_letter のまま（`view_letter` は ADR-0072 の D4 (c)）。
3. **D3 変わらないこと**: コンテンツへの操作（掲示板の投稿の取り下げ・維持、通報の `closed` / `dismissed`）、
   住民どうしのブロック（FR-068）、モデレーターの操作の記録（`moderation_actions`、ADR-0013 の 1 年）、
   段階 2 の異議の手続き（`roadmap.md` S2-5、F-14）は今までどおり。S2-5 は投稿の取り下げへの異議として進め、住民への処置への異議は OQ-048 の答えのあとに足す。

## 理由

- 内容を後で決めることは、マスターの答え（上の原文）による。
- 実行する手段を先に作らないのは、作ると処置の種類（停止か警告か）と重さを先に決めることになり、マスターが後で決めるとした内容を秘書が決めてしまうため。
- 投稿の取り下げとブロックで、違反した内容は住民に届かなくできる。処置の手段がなくても MVP の受け入れ条件は満たせる。
- OQ-048 を「要回答」ではなく「持ち越し」にするのは、マスターが「後ほど決定」と答えており、すぐ聞き直すと答えと食い違うため。
  デプロイしない間は、処置の手段がなくても困らない（OQ-047 と同じ扱い）。

## 代わりの案（選ばなかった理由）

- **警告だけを暫定で作る**: 処置の種類を先に決めることになり、答えと食い違う。
- **`moderation_actions` に処置の種類の値（例: `suspend`）だけ足しておく**: 実行しない値を記録すると、処置が行われたように見える。種類を先に決めることにもなる。
- **OQ-048 を要回答にしてすぐ聞き直す**: 上のとおり、答えと食い違う。

## 決めていないこと

- 処置の種類・重さ・住民への通知・異議の手続き: OQ-048（持ち越し）。

## 影響

内容が決まったら、次を直す。

- `security.md`: §1 原則 1、§3.4 と ADR-0019 の再認証が要る操作、§4.2 の権限の表、§5.4 の 6、§7 の T-12、§8。
- `api.md`: §7 F-08 の `POST /api/v1/admin/reports/{id}/actions` の操作の種類（と、住民を停止する経路を足すなら、その経路）。
- `db.md`: §2 の `moderation_actions.action` の値（と、住民の状態を持つなら `residents` の列）・§4 のライフサイクル・§9。
- `roadmap.md`: S2-5 の異議の手続き・§8・受け入れ条件 A-09。
- `features.md` §5 の FR-081 の処置。

この ADR で直したもの: `open-questions.md`（OQ-037 を決定に、OQ-048 を足す）・`security.md`・`roadmap.md`（A-09 に、住民を停止・警告する経路がないことの確認を足す）・
