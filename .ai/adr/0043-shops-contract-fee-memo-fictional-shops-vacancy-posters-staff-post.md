# 0043 — 商店とは契約を結び利用料を取る考え（MVP ではメモだけ）。架空の店を置いてよく、空いた区画には金額を載せない入居者募集の張り紙を出す。発信はお店の担当者が行い、出せるものは広さと料金のランクで変える（折込チラシが最高）。商店は実在の情報を出してよい

- 状態: 採用
- 日付: 2026-11-20

## 背景

OQ-045 の答え（ADR-0038 の D1）で、商店には実在の企業・個人のお店を迎えることを目指すと決まった。
迎え方は答えに書かれていなかったので、`open-questions.md` の OQ-056 でマスターに次の 5 点を聞いていた。
(1) 実在の店の選び方・本物であることの確かめ方、契約を結ぶか・利用料を取るか。
(2) 実在の店が来るまで、運営が作る架空の店を置くか。置くなら架空と示すか。
(3) 管理者が商店のアカウントを作ったあと、商店として発信するのは誰か（(a) 管理者が代わりに書く、(b) お店の担当者に渡す）。
(4) 商業の発信で何を許すか。広告・折込チラシ（F-20、このフェーズの範囲外）との境。
(5) 経営者の名前など、実在の人の情報をどこまで出すか。
暫定はなく、F-17 の商店の部分は OQ-056 の答えまで止まっていた（ADR-0022 の決定 6、ADR-0038 の D1）。

2026-11-20、マスターが OQ-056 に次のとおり答えた（原文）。

> １：MVPでは商店の具体的仕組みは必要ないので、メモだけ残して。今の考えとしては、契約を結び利用料を取る。場所の広さ、新聞への頻度の高さ、大きさに比例して利用料を決定するような形。
> ２：架空でOK。開いてる商店には入居者募集的な張り紙を導入したい。これもMVP時点では仮でOK。内容は、広さによって決定される、新聞への掲載頻度と記事の大きさ。金額についてはLPなどに問い合わせを設けて、そこから連絡をもらい資料内に記載する。入居者募集張り紙に具体的な金額は載せない
> ３：お店の担当者。
> ４：MVPで不要のため、改めて時期が来たら考えるが、広さと料金によって出せるものを変える。折込チラシはそのランクの中の最高
> ５：商店は実在の情報を出してOK

答えから読み取れることと、読み取れないことを分ける。

- 答え 1: MVP では商店の具体的な仕組みは要らない。今の考えとして、実在の店とは契約を結び、利用料を取る。利用料は、場所の広さ・新聞に載る頻度・記事の大きさに比例させる。
  「メモだけ残して」とあるので、方向として残し、仕組みにはしない。本物であることの確かめ方・契約の形・料金の関係の中身は書かれていない。
- 答え 2: 「架空でOK」を、問い (2)「実在の店が来るまで架空の店を置くか」への答えと読む（秘書の読み方）。架空の店をいつ置くか・架空と示すか・架空の店が発信するかは書かれていない。
  「開いてる商店」は、文の流れ（入居者募集の張り紙を出す相手）から「空いている商店の区画」と読む（秘書の読み方）。
  張り紙の中身は、広さで決まる「新聞に載る頻度」と「記事の大きさ」で、MVP の時点では仮でよい。金額は張り紙に載せず、LP などの問い合わせから連絡を受け、資料の中で伝える。
  答えから、商店には広さのある区画があり、空いた区画もあると読み取れる。区画の持ち方（割り当て方・広さの段数）は書かれていない。
- 答え 3: 商店として発信するのは、お店の担当者（問い (3) の (b)）。担当者のログインの方法と権限は書かれていない。
- 答え 4: 中身は MVP で不要で、時期が来たら考える。出せるものは広さと料金（のランク）で変え、折込チラシはランクの中の最高に置く。ランクの段数とそれぞれで出せるものは書かれていない。
- 答え 5: 商店は実在の情報を出してよい（問い (5) への答えと読む）。どの項目を出すか・どう持つかは書かれていない。
  答えの対象は商店（お店）で、担当者（答え 3 で初めて出てきた人）・経営者など個人の情報をどこまで出すかは書かれていない。
- 答えに「MVPでは」「MVP時点では仮でOK」とある一方、F-17 は段階 3 にある。架空の店と張り紙を MVP に入れる意図かは読み切れない（OQ-067 (1)）。
  （2026-11-20 更新: OQ-067 → 決定（ADR-0050）。MVP には入れず段階 3 から作る。残りは OQ-083・OQ-084）

## 決定

1. **D1 契約と利用料はメモだけ**（答え 1、`[inferred]`）:
   実在の店とは契約を結び、利用料を取る考えとする。利用料は、場所の広さ・新聞に載る頻度・記事の大きさに比例させる。
   答えに「メモだけ残して」とあるので、方向として残すだけで、仕組みにはしない。MVP では商店の具体的な仕組みを作らない。
   料金の関係・ランク・契約の形・本物であることの確かめ方の中身は OQ-068（持ち越し、マスターが決める）にする。
2. **D2 架空の店を置いてよい**（答え 2「架空でOK」、`[inferred]`）:
   実在の店が来るまで、架空の店を置いてよい（問い (2) への答えと読むのは秘書の読み方）。
   いつ置くか・架空と住民に示すか・架空の店が発信するかは OQ-067（要回答）にする。
   （2026-11-20 更新: OQ-067 → 決定（ADR-0050）。段階 3 から置き、「入居者募集」の張り紙で架空と示し、発信させず新聞にも載せない（ADR-0050 の D1〜D4）。残りは OQ-083・OQ-084）
3. **D3 入居者募集の張り紙**（答え 2、`[inferred]`）:
   空いている商店の区画に、入居者募集の張り紙を出す（「開いてる」を「空いている」と読むのは秘書の読み方）。
   張り紙の中身は、広さで決まる「新聞に載る頻度」と「記事の大きさ」とする。答えに「仮でOK」とあるので、この中身は暫定とする。
   具体的な金額は張り紙に載せない。金額は LP などの問い合わせから連絡を受け、資料の中で伝える。
   LP・問い合わせ・資料はアプリの外にあり、今は計画として書くだけで、作らない・公開しない（デプロイしない）。
   商店は広さのある区画を持ち、空いた区画もある。区画の割り当て方と広さの持ち方は OQ-069（持ち越し）にする。
4. **D4 発信するのはお店の担当者**（答え 3、`[inferred]`）:
   商店として発信するのは、お店の担当者とする。商店のアカウントは ADR-0029 の D1・D2 のまま運用者の CLI で作り、担当者に渡す（ADR-0029 は変えない）。
   商店の発信は ADR-0038 の D4 のまま配達の前に審査し、承認の前には出さない。
   担当者のログインの方法（C2）と、発信する主体・権限（C3、`security.md` §4）は OQ-069 にする。
5. **D5 出せるものは広さと料金のランクで変える**（答え 4、`[inferred]`）:
   商店が出せるものは、広さと料金によるランクで変える。折込チラシはランクの最高に置く。
   F-20（広告・折込チラシ）はこのフェーズの範囲外のままとし、FR-090 は変えない。ランクの段数とそれぞれで出せるものは OQ-068 にする。
6. **D6 商店は実在の情報を出してよい**（答え 5、`[inferred]`）:
   商店（お店）は、お店の実在の情報（お店の名前など）を出してよい（問い (5) への答えと読む）。
   `security.md` §2.2（収集しないもの）の例外は、お店の実在の情報についての「実名・氏名」の項目だけとする。
   ほかの項目（電話番号・顔写真・位置情報・決済情報など）は、OQ-068・OQ-069 で決めるまで商店にも当てる。住民について実名を集めないことは変えない。
   担当者・経営者など個人の情報をどこまで出すかは、答えに書かれておらず、公開の範囲にかかわるので決めない。OQ-069 (3) に含め、S3-2 の前にマスターに聞く。
   レポジトリ・テスト・シードに実在の企業・お店・人の名前を入れないこと（ADR-0038 の D5）も変えない。
   出す項目と持ち方は OQ-069 にする。
7. **D7 段階**（秘書の判断）: F-17 は段階 3（S3-2）のままとする（OQ-067 (1) の暫定）。MVP には商店のものを作らない。
   商店の部分は、もう要回答では止まらない。S3-2 では、OQ-068 の答えと OQ-069 の ADR のあとに作る（ADR-0022 の決定 6）。
   （2026-11-20 更新: OQ-067 (1) → 決定（ADR-0050 の D1）。暫定のとおり段階 3 から作る。残りは OQ-083・OQ-084）
8. **D8 要求の区分**: ADR-0024 の決定 5 に従い、FR-104・FR-047 を直し、根拠にこの ADR を足す。
   架空の店と張り紙の要求として FR-116、担当者の発信・ランク・実在の情報の要求として FR-117 を足し、どちらも `[inferred]`（マスターの答え OQ-056（2026-11-20）より）とする。

## 理由

- D1 は、答え 1 の「メモだけ残して」による。料金は費用（NFR-080）にかかわり、答えに「今の考え」とあるので、仕組みや数値は決めず、中身はマスターに聞く（OQ-068）。
- D2・D3 は、答え 2 による。張り紙の中身は答えに書かれた 2 つ（頻度と大きさ）だけにし、金額の項目を持たない。金額をアプリの外で伝えるのは答えのとおり。
  LP と問い合わせは外部の公開と個人の連絡先にかかわるので、作らず計画として書くだけにする（CLAUDE.md の「デプロイ・外部のサービスはしない」）。
- D4 は、答え 3 による。アカウントを作る経路を運用者の CLI に保つのは、ADR-0029 の D2（API が侵害されても作れない）のまま。
  審査を残すのは、商店の発信も誰でも読める公開の内容になるから（ADR-0038 の D4）。
- D5 は、答え 4 による。答えに「MVPで不要」「時期が来たら考える」とあるので、F-20 の範囲は今は変えない。
- D6 は、答え 5 による。答えは商店が公開してよい情報についてのもので、住民の実名を集めない決まりとは対象が違う。
  集めない情報の決まりを商店について緩めるのは、答えにある「お店の実在の情報」だけにし、ほかの項目（電話番号・顔写真・位置情報・決済情報）は答えにないので緩めない。
  個人の情報の公開は実在の人にかかわり、マスターにしか決められない（CLAUDE.md の「公開の範囲」）。公開レポジトリに実在の名前を書かない決まり（CLAUDE.md）は運用のデータには当たらず、レポジトリの決まりとして残る。
- D7 は、答えに MVP に入れるとは書かれておらず、F-17 は段階 3 にあるから。入れるかはマスターに聞く（OQ-067 (1)。2026-11-20 更新: → 決定、MVP には入れない、ADR-0050 の D1）。
  残りの中身（OQ-068・OQ-069）は段階 3 の実装もデプロイもしない間は要らないので、S3-2 の前に決める。

## 代わりの案（選ばなかった理由）

- **契約と利用料の仕組み・料金の数値をこの変更で決める**: 答えに「メモだけ残して」とあり、費用にかかわる（OQ-068）。
- **張り紙に金額や目安を載せる**: 答えの「入居者募集張り紙に具体的な金額は載せない」と食い違う。
- **LP と問い合わせの窓口を作る**: アプリの外の公開で、デプロイしない。計画として書くだけにする。
- **管理者が代わりに発信する**: 答え 3「お店の担当者」と食い違う。
- **担当者が自分で商店のアカウントを作る**: ADR-0029 の D1・D2 と食い違い、答えはアカウントを作る経路に触れていない。
- **架空の店と張り紙を MVP に入れる**: F-17 は段階 3 で、答えの「MVPでは」が MVP に入れる意図かは読み切れない（OQ-067 (1)）。
  （2026-11-20 更新: OQ-067 → 決定（ADR-0050）。マスターの答えで MVP には入れないと決まった）
- **商店でもお店の実在の情報を出さない**: 答え 5 と食い違う。
- **担当者・経営者の個人の情報も出してよいと決める**: 答え 5 は商店についてのもので、個人の情報の公開の範囲はマスターに聞く（OQ-069 (3)）。
- **§2.2 の全体を商店に当てない**: 答えにない項目（電話番号・顔写真・位置情報・決済情報）まで集めてよいことになり、守りを緩める。

## 決めていないこと

- 架空の店と張り紙をいつ・どう出すか（OQ-067、要回答）: (1) MVP に入れるか・どこに出すか、(2) 架空の店と住民に示すか、(3) 架空の店が発信するか・誰が書くか（FR-110 と ADR-0039 の D6「運営が書く架空の記事は使わない」との関係）。
  暫定: 段階 3 のままで MVP には作らない。架空の店は発信しない。
  （2026-11-20 更新: OQ-067 → 決定（ADR-0050）。残りは OQ-083（新聞の入居者募集の広告をいつから出すか、要回答）・OQ-084（架空の店と張り紙・広告の出し方の細部、持ち越し））
- 商店の契約・利用料・ランクの中身（OQ-068、持ち越し。マスターが決める）: 料金の関係、ランクの段数とそれぞれで出せるもの、契約の形、本物であることの確かめ方、LP・問い合わせ・資料（問い合わせで受ける情報の扱いを含む）。
- 担当者のログイン・主体・権限、区画の割り当てと広さ、実在の情報の項目、新聞への載せ方（OQ-069、持ち越し。S3-2 の前に秘書が ADR で決める）。
  ただし (3) のうち、担当者・経営者など個人の情報をどこまで出すかは公開の範囲にかかわるので、秘書は決めず S3-2 の前にマスターに聞く。
  地図に商店を描くか（ADR-0037・ADR-0042）は OQ-069 と OQ-084 (2) に含める（2026-11-20 更新: OQ-067 は決定（ADR-0050））。
