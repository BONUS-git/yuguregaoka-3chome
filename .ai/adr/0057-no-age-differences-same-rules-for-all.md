# 0057 — 年齢による違いは作らず、全員に同じ基準を当てる

- 状態: 採用
- 日付: 2026-11-21

ADR-0047 を丸ごと置き換える。ADR-0047 の決定（D1〜D7）は、OQ-076 の答え（2026-11-21、いまは ADR-0069）で D1 の暫定がなくなったので、今の状態に書き直して同じ番号でこの ADR に移した。新しい決定はない。

## 背景

OQ-052 の答え「３：変える。」（2026-11-20）で、住民の年齢で守り方を変えると決めた（ADR-0041 の D1）。
何を変えるか・年齢の区切りは答えに書かれていなかったので、`open-questions.md` の OQ-063 でマスターに聞き、2026-11-20 に次のとおり答えが出た（原文。ADR-0047）。

> 暫定の通り「年齢による違いは作らない」で進めて。
>
> (1) 手紙と掲示板のブロック対象は、年齢に関係なく全ユーザー共通の基準でフィルタリングする。特定の年齢層だけに別の言葉を出すような複雑なことはしない。一律、問題がある記載は一才許可しない
> (2) 機能の解放条件も年齢に紐付けない。詐欺防止や事件防止についても、年齢で制限するのではなく、システム全体の共通ルール（スパム検知や不審な挙動への対処）として実装すること。
> (3) 年齢による区切りは設けない。
>
> 「年齢で守り方を変える」という言葉の意図は、将来的に「もし変えるとしたら」という拡張性や、データ構造として年齢を持っておくこと、あるいは年齢によって（属性として）表示が変わる可能性を含んでいるだけで、実装レベルで年齢ごとにフィルタリングロジックを分岐させるコストは払わない。シンプルに、全員に同じルールを適用する。

答え (1) の「一律、問題がある記載は一才許可しない」が、当たった手紙を送った人の確認とモデレーターの承認でも届けず一律に止めるという意味かは、OQ-076 で聞いた。
2026-11-21 の答え（いまは ADR-0069）は「1の方針」（年齢で例外を作らず、当たった手紙は送った人の y / n とモデレーターの確認で扱う）を土台にし、
直接的な性的な言葉・外部へのリンク・本当の居住地や年齢を聞くことを絶対NG（確認に回さずに止める）、その疑いをモデレーター確認に分けた。
そこで、この ADR の「一律」は年齢で例外を作らないことと読む。絶対NGと疑いの段は ADR-0069 の D10〜D12 で、手紙のほかの書き込みへの絶対NGは ADR-0070 で、どれも年齢に関係なく全員に同じに当てる。

答えは、ADR-0041 の D1（年齢で守り方を変える）を置き換える。ADR-0041 の D2〜D4・D6（年齢は住民の設定をそのまま使う・危険な機能は設けない・生年月日は集めない・登録に年齢制限を置かない）は変わらない。
年齢と誕生日の扱い（登録で必須・変えられない・誕生日に進む・本人から手紙を受け取った住民にだけ見せる・誕生日は知り合いの紙面にだけ載せる）は OQ-064 の答え（2026-11-20）と OQ-077 の答え（2026-11-21）で決まった（ADR-0093・ADR-0074）。

## 決定

区分は ADR-0024 の決定 5 に従う。

1. **D1 止める基準を年齢で変えない**（OQ-063 の答え 1・OQ-076 の答え「1の方針」、`[inferred]`）: 手紙（ADR-0069 の D1・D10〜D13）と掲示板（ADR-0005・ADR-0031）とほかの書き込み（ADR-0070）で止める基準は、送る人・受け取る人の年齢に関係なく、全員に同じにする。
   - ルール表（`security.md` §5.1）の項目に年齢の条件を持たせない。年齢層ごとに別の言葉の一覧を持たない。段（`reject` / `review`）にも年齢の条件を持たせない。
   - 当たった手紙の扱いは ADR-0069 のとおり: `reject` の段は確認に回さずに 422（`letter_rejected`）、`review` の段は送った人が y / n を選び、y の手紙をモデレーターが確かめて承認すれば届く。
     絵文字を入力できないこと（ADR-0069 の D13・ADR-0070 の D2）と、手紙のほかの書き込みの 422（`content_rejected`、ADR-0070 の D3）も、年齢に関係なく全員に同じ。
2. **D2 使える機能を年齢で変えない**（答え 2、`[inferred]`）: 機能を使える条件・権限（`security.md` §4.2・C3 の権限の規則）に年齢の条件を持たせない。
   マッチング（F-18）への参加にも年齢条件を置かない（FR-064）。
3. **D3 詐欺と事件の防止は、全員に同じ共通のルールで行う**（答え 2、`[inferred]`）: 高齢の住民を詐欺から、若い住民を事件から守ること（OQ-043 の答え、ADR-0036）は、
   年齢での制限でなく、全員に同じに効く仕組みで行う。今ある仕組みは、手紙の照合（2 段。本当の居住地・本当の年齢・街の外の連絡先の照合を含む、ADR-0069 の D1・D12）・全ての書き込みの絶対NG（ADR-0070）・掲示板の審査・送信の上限（ADR-0005）・
   通報・ブロック・街の外の連絡先を全ての書き込みで渡させないこと（FR-101、ADR-0071）。どれも住民が自分で外せない（ADR-0036 の D3）。
   - 「不審な挙動への対処」の中身は今の文書に設計がない。OQ-075（持ち越し）にし、M4 を始める前に秘書が ADR で決める（秘書の判断）。
     そこで決めるのは、どの挙動を不審と見るか・何をするか（流量の制限・モデレーターへの知らせなど）で、年齢の条件は持たせない。
   - 住民への処置（アカウントを止めるなど）の中身は、OQ-048（持ち越し、ADR-0032）でマスターが決める。OQ-075 では処置を決めない。
4. **D4 年齢の区切りを置かない**（答え 3、`[inferred]`）: 何歳未満・何歳以上という区切りを、文書・設定・コードに置かない。
5. **D5 ADR-0041 の D1 を置き換える**: ADR-0041 の D1「年齢で守り方を変える」は、この ADR の D1〜D4 で置き換える。
   - ADR-0041 の D2（年齢は住民の設定をそのまま使い、確かめない）・D3（危険な機能は設けない）・D4（生年月日は集めない）・D6（登録に年齢制限を置かない）は変わらない。
   - 年齢の項目と `residents` の列は ADR-0093 のとおり置く（年齢と誕生日は登録で必須・変えられない・誕生日に進む・本人から手紙を受け取った住民にだけ見せる）。年齢で守りと権限を変えないこと（D1〜D4）は変わらない。
6. **D6 ADR-0027 の「特別な制限を置かない」**: ADR-0041 の D1 で置き換えていた ADR-0027 の D2 の「特別な制限を置かない」は、この ADR で実質もとに戻る（年齢で違いを作らないので、未成年だけに効く制限もない）。
   年齢と誕生日（月日）は ADR-0093 の D5・D7 のとおり登録で必須で集める。年を含む生年月日を集めないことは変わらない。
7. **D7 要求の区分**: FR-064・FR-094・FR-113 は年齢で違いを作らない形にし、FR-120（詐欺と事件の防止は全員に同じ共通のルールで行う）を置く。どれも `[inferred]`（マスターの答え OQ-063（2026-11-20）より）。

## 理由

- D1〜D4 は OQ-063 の答えのとおり。年齢ごとにルール表と権限を分けないので、照合と権限の規則が 1 通りで済み、テストも 1 通りで済む（答えの「コストは払わない」）。
- D1 の「一律」を年齢で例外を作らないことと読むのは、OQ-076 の答えが「1の方針」を選んだため。当たった手紙の扱い（絶対NGと疑い）は ADR-0069 にまとめ、この ADR では年齢の条件を持たせないことだけを決める。
- D3 は、年齢を確かめない（ADR-0041 の D2）ので、年齢で制限しても年齢を偽れば外れる。全員に同じに効く仕組みなら、年齢を偽っても外れない。
  「不審な挙動への対処」は技術と設計で決められるので、秘書が持ち越しで決める（CLAUDE.md の「要回答」の範囲の外）。

## 代わりの案（選ばなかった理由）

- **成人向けの言葉を、ある年齢より下の住民の手紙にだけ当てる**: 答え 1「特定の年齢層だけに別の言葉を出すような複雑なことはしない」と食い違う。
- **マッチングを一定の年齢以上に限る**: 答え 2「機能の解放条件も年齢に紐付けない」と食い違う。
- **当たった手紙を送った人の確認も許さずにすべて止める**: OQ-076 の答えが「1の方針」を選び、疑いはモデレーター確認とした（ADR-0069）。
- **「不審な挙動への対処」の中身をこの ADR で決める**: 何を不審と見るかは、手紙の照合の細部（OQ-065）・違法な物の取引の守り（OQ-053）とあわせて決めるほうがそろう。

## 決めていないこと

- 「不審な挙動への対処」の中身（何を不審と見るか・何をするか）: OQ-075（持ち越し。M4 を始める前に秘書が ADR で決める）。
- 年齢の属性で何の表示が変わるか: OQ-078（持ち越し、暫定は作らない）。
- 住民への処置の中身: OQ-048（持ち越し）。手紙の照合の細部: OQ-065（持ち越し）。違法な物の取引の守り: OQ-053（持ち越し）。
- 適用法令が未成年の利用について何を求めるか: OQ-032（持ち越し）。
