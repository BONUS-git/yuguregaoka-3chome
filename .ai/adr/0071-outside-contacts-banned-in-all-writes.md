# 0071 — 街の外の連絡先は全ての書き込みで止める

- 状態: 採用
- 日付: 2026-11-22

ADR-0034 を丸ごと置き換える。ADR-0034 の D1・D4・D5 はそのまま、D2・D3 は OQ-087 の答えに合わせて書き直し、同じ番号でこの ADR に移した。

## 背景

OQ-001 の答え（2026-11-19、ADR-0024）で「個別に連絡先の共有などは絶対禁止にする予定」と決まり、住民どうしが個別に連絡先を共有することを禁止した（FR-101、ADR-0024 の D3）。
OQ-041 の答え（2026-11-19）で、「連絡先」は街の外の連絡先だけで、禁止はマッチングの中だけと決まった（原文「街の外の連絡先のみ。禁止はマッチングの中のみ。掲示板・手紙への禁止は及びません。」）。
OQ-076 の答え（2026-11-21）で、手紙で本当の居住地や年齢などを聞く文を絶対NGにした（ADR-0069 の D12）。そのうえで OQ-087 で、「など」に連絡先が入るか・自分から書くことも止めるかを聞いた。
2026-11-22、マスターが次のとおり答えた（原文）。

> 絶対NGと絵文字不可を全てに適用。対象に連絡先や自分から書くことも含める。

答えは、連絡先を絶対NGの対象に入れ、絶対NGを全ての書き込みに当てる（ADR-0070）。OQ-041 の答えの「禁止はマッチングの中のみ」は、この新しい答えで広がったと読む `[inferred]`。

## 決定

1. **D1 「連絡先」は街の外の連絡先だけ**（OQ-041 の答え）: 禁止する「連絡先」は、街の外の連絡先（メールアドレス・電話番号・他のサービスのアカウント・実在の住所など）だけとする。
   街の住所（夕暮ヶ丘三丁目の住所）は含まない。成立後は街の中の手紙でやり取りする（FR-067・ADR-0024 の D2）は変わらない。
2. **D2 禁止は全ての書き込みに及ぶ**（OQ-087 の答え、`[inferred]`）: 街の外の連絡先を書くことは、マッチングの中だけでなく、手紙・掲示板の投稿・商店街の発信・プロフィール・住所録のメモ・通報の理由（ADR-0070 の D1）のどれでも止める。
   相手に聞くことも、自分の連絡先を書くことも、ほかの人の連絡先を書くことも止める。
3. **D3 止め方はルール表の `real_info`**（`[assumed]`）: ルール表の `real_info`（ADR-0069 の D12）が街の外の連絡先を扱う。はっきりした形（メールアドレス・電話番号の形の文字列など）は `reject` の段で、手紙は 422 `letter_rejected`、ほかの書き込みは 422 `content_rejected`（ADR-0070 の D3）。
   疑いの形（`review` の段）は手紙だけで確かめる（y / n とモデレーターの確認）。手紙のほかの書き込みでは、`reject` の段に当たるはっきりした形だけを止め、疑いの形は止めない。J2 の掲示板向けの項目と LLM の基準に `real_info` は入れない（ADR-0070 の D3）`[assumed]`。URL は `external_link` で止める。
   商店（実在の店、ADR-0038）の発信も同じに止める。商店の実在の情報（店の名前・営業の案内）を出せること（ADR-0043）は、連絡先を除いて変わらない `[assumed]`。
4. **D4 変わらないこと**: マッチングの参加の登録と提案に街の外の連絡先の欄を設けない（ADR-0024 の D3）、
   恋愛のカテゴリを設けない（ADR-0024 の D1）、年齢条件を置かない（ADR-0027）、成立後は街の中の手紙でやり取りする（FR-067）、
   ブロック・通報・審査と連絡先の共有の禁止は、年齢に関係なくすべての住民に同じに効く（ADR-0057）。
5. **D5 マッチングの中での守り方の細部は OQ-050**（持ち越し）: (1) 参加の登録に自由記述の欄を設けるか（設けるなら ADR-0070 の D1 の範囲に入り、D3 で止める）、
   (2) 成立後に最初の手紙を出す方法（提案に相手の街の住所を載せるか）は、S3-3 のマッチングのアルゴリズムの ADR（FR-066）で決める。

## 理由

- D1 は OQ-041 の答えのまま。
- D2 は OQ-087 の答え「対象に連絡先や自分から書くことも含める」と「全てに適用」による。連絡先の共有の禁止（FR-101）と本当の情報の絶対NGが同じものを止めるので、範囲を 1 つにそろえる。
- D3 で連絡先を 1 つの種類に集めるのは、止め方（段・応答・件数の見張り）を全ての書き込みで同じにするため。
- D5 は技術と設計で決められることで、マッチングの仕組みを決める ADR と一緒に決めるのが自然なため（持ち越し）。

## 代わりの案（選ばなかった理由）

- **禁止はマッチングの中だけのまま、`real_info` を別の理由の項目にする**: 同じ連絡先を、FR-101 では止めず `real_info` では止める二重の説明になり、文書が食い違いやすい。
- **街の住所も「連絡先」に含める**: OQ-041 の答え（街の外の連絡先のみ）と食い違う。成立後に手紙でやり取りできなくなる。
- **商店の発信だけ連絡先を許す**: 答えは「全てに適用」で、例外を書いていない。商店の問い合わせの道筋は OQ-084 (4) で決める。

## 決めていないこと

- マッチングの中での守り方の細部（自由記述の欄と、成立後に最初の手紙を出す方法）: OQ-050（持ち越し、S3-3 のアルゴリズムの ADR で決める）。
- 連絡先の形の細部: OQ-065（持ち越し）。
- 禁止に違反した住民への処置: OQ-048（持ち越し、ADR-0032）。
- 商店の広告・張り紙の問い合わせの道筋: OQ-084（持ち越し）。
