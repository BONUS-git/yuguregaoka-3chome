# 0050 — 架空の店と入居者募集の張り紙は段階 3 から作る（MVP には作らない）。架空の店には「入居者募集」の張り紙を出して架空と分かるようにし、発信させず新聞にも載せない。新聞には運営の入居者募集の広告を出す

- 状態: 採用
- 日付: 2026-11-20

## 背景

ADR-0043 の D2・D3 で、実在の店が来るまで架空の店を置いてよく、空いている商店の区画には金額を載せない入居者募集の張り紙を出すと決めた。
いつ・どう出すかは答えに書かれていなかったので、`open-questions.md` の OQ-067 でマスターに次の 3 点を聞いていた。
(1) 架空の店と張り紙を MVP に入れるか（F-17 は段階 3）・どこに出すか。
(2) 架空の店だと住民に示すか。
(3) 架空の店が発信するか・誰が書くか（FR-110 と ADR-0039 の D6「運営が書く架空の記事は使わない」との関係）。
暫定は、段階 3 のままで MVP には作らない、架空の店は発信しない（ADR-0043 の D7）だった。

2026-11-20、マスターが OQ-067 に次のとおり答えた（原文）。

> １：暫定の考えの通り、MVPには入れない。商店街（F-17）は段階3の機能なので、MVP時点では架空の店も張り紙も作らない。段階3から開始する。
>
> ２：段階3で実装する際に、架空の店であることがわかるようにする（「入居者募集」の張り紙が出ている状態にする）。
>
> ３：架空の店は発信しない。新聞の素材に「運営が書く架空の記事は使わない」という決まり（FR-110）に抵触させないため、架空の店が新聞に載ることはない。あくまで「店が入るための場所（区画）がある」ことを示すためのもので、店として活動はさせない。新聞に入居者募集の広告は出す。ユーザーが事業を持っている可能性もあるため。

答えから読み取れることと、読み取れないことを分ける。

| 答え | 読み取れること（決定） | 読み取れないこと（新しい OQ） |
|---|---|---|
| 1「MVPには入れない…段階3から開始する」 | 架空の店と張り紙は段階 3（S3-2）から作る。MVP には作らない | どこに出すか（地図・住所録・掲示板）は書かれていない → OQ-084 (2) |
| 2「架空の店であることがわかるようにする（「入居者募集」の張り紙が出ている状態にする）」 | 架空の店には「入居者募集」の張り紙を出し、それで架空と分かるようにする | 架空の店の名前・見た目、空いた区画との違い → OQ-084 (1) |
| 3「架空の店は発信しない…新聞に載ることはない…店として活動はさせない」 | 架空の店は発信せず、新聞にも載らない。区画があることを示すだけのもの。FR-110 はそのまま | — |
| 3「新聞に入居者募集の広告は出す」 | 新聞に入居者募集の広告を出す（新聞の素材の出どころが 1 つ増える） | いつから出すか（答え 1 は架空の店と張り紙の時期だけを決めている）→ OQ-083（2026-11-21 の答え「a」で、段階 3（S3-2）から）。載せ方・中身 → OQ-084 (3)(4) |

## 決定

区分は ADR-0024 の決定 5 に従う。

1. **D1 段階 3 から**（答え 1、`[inferred]`）: 架空の店と入居者募集の張り紙は、段階 3（S3-2、F-17）から作る。MVP には作らない。
   ADR-0043 の D7 の暫定が、そのまま決定になる。
2. **D2 張り紙で架空と示す**（答え 2、`[inferred]`）: 架空の店には「入居者募集」の張り紙が出ている状態にし、それで架空の店だと分かるようにする。
   ほかの示し方（「架空」の札など）は足さない。張り紙の中身は ADR-0043 の D3 のまま（広さで決まる新聞に載る頻度と記事の大きさ、金額は載せない）。
3. **D3 架空の店は発信しない**（答え 3、`[inferred]`）: 架空の店は、店が入るための場所（区画）があることを示すだけのもので、店として活動させない。
   秘書の判断として、これを次の形にする。架空の店には、発信の経路（API・運用者の CLI のどちらにも）も、担当者のアカウントも作らない。
   同じ理由で、架空の店は手紙の宛先にもならず、架空の店との手紙は扱わない（OQ-082 の「商店との手紙」の対象から外す）。
4. **D4 架空の店は新聞に載らない**（答え 3、`[inferred]`）: 架空の店の記事も発信も、新聞の素材と紙面に入れない。
   FR-110 と ADR-0039 の D6 の「運営が書く架空の記事は使わない」は変えない。
5. **D5 新聞に入居者募集の広告を出す**（答え 3、`[inferred]`）: 新聞に、運営が出す入居者募集の広告を載せる。
   - 秘書の判断: この広告は運営が出す本物の募集で、架空の記事ではない。だから FR-110 と食い違わない。
   - 秘書の判断: この広告は F-20（企業広告・折込チラシ、このフェーズの範囲外、FR-090）に含めず、F-17・FR-116 の一部とする。
     F-20 に入れると、答えの「出す」がこのフェーズでできなくなるから。
   - 表示数・クリック数を見せない決まり（FR-085）は、この広告にも当てる。
   - 段階 3（S3-2）から出し、MVP の紙面（C6）に広告の枠を置かない（OQ-083（2026-11-21）「a」）。載せ方と中身の細部は OQ-084（持ち越し）。
6. **D6 要求の区分**: FR-116 を直し、FR-123（新聞の入居者募集の広告）を §3.5 に足す。どちらも `[inferred]`（マスターの答え OQ-067（2026-11-20）より）。
   FR-110・FR-035・FR-090 に参照を添える。

## 理由

- D1・D2・D4 と D5 の「出す」は、答えの原文による。D1 は暫定と同じで、MVP の範囲（ADR-0022）を変えない。
- D3 で発信の経路と担当者のアカウントを作らないのは、答えの「店として活動はさせない」を技術の形にするため。経路がなければ、運用の誤りでも架空の店が発信することはない。
  手紙を扱わないのも、手紙のやりとりは店としての活動にあたるから。
- D5 で広告を本物の募集とみなすのは、運営が実在の入居者を本当に募るもので、作り話ではないから。FR-110 が禁じているのは、運営が書く架空の記事である。
- D5 で広告を F-20 に含めないのは、F-20 はこのフェーズの範囲外（FR-090）で、含めると答えの「新聞に入居者募集の広告は出す」と食い違うから。
  FR-085 を当てるのは、即時性と数値の評価を持ち込まない原則（`requirements.md` §1.3）が広告にも当たるから。
- 広告を段階 3（S3-2）から出すのは、マスターの答え（OQ-083（2026-11-21）「a」）による。答え 1 が決めたのは「架空の店も張り紙も」の時期だけで、広告の時期は MVP の範囲にかかわるのでマスターに聞いた。MVP の範囲（ADR-0022）は変わらない。

## 代わりの案（選ばなかった理由）

- **架空の店に「架空」の札を足す**: 答え 2 は示し方を「「入居者募集」の張り紙が出ている状態」と書いている。それ以上の示し方は答えにない。
- **架空の店に発信させる（運営が書く）**: 答え 3「架空の店は発信しない」と、FR-110 の「運営が書く架空の記事は使わない」に反する。
- **入居者募集の広告を F-20 に入れる**: F-20 はこのフェーズの範囲外で、答えの「新聞に入居者募集の広告は出す」がこのフェーズでできなくなる。
- **広告を MVP（M5）から出す**: マスターの答え（OQ-083「a」）は段階 3 から。MVP の時点では商店の区画・契約の仕組みがなく（ADR-0043 の D1・D7）、広告を見た住民の問い合わせ先もない。
- **広告に金額を載せると決める**: ADR-0043 の D3 で張り紙に金額を載せないと決めており、広告の中身は答えにない。費用と公開にかかわるので、OQ-068 と一緒にマスターに聞く（OQ-084 (4)）。

## 決めていないこと

- 架空の店と、張り紙・広告の出し方の細部（OQ-084、持ち越し）: (1) 架空の店の持ち方（名前・見た目、空いた区画との違い）、(2) 張り紙と架空の店をどこに出すか（地図・住所録・掲示板）、
  (3) 広告の載せ方（枠・頻度・どの版か・文を決まった文にするか LLM が書くか。ADR-0046 との関係）、(4) 広告の中身（金額を載せるか・問い合わせの道筋）。
  S3-2 の前に秘書が ADR で決める。ただし (4) は費用と公開にかかわるので、OQ-068 と一緒にマスターに聞く。暫定は置かず、決まるまで作らない。
