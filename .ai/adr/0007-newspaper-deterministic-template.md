# 0007 — 新聞はテンプレートで決定的に組む

- 状態: 採用（全住民に届けることを ADR-0035 で追加。紙面の中身は OQ-051 の答えで変わりうる）
- 日付: 2026-11-19

## 背景

FR-033 では組版バッチが朝刊を自動生成し、FR-037 では冪等性が要求されている。
組版に LLM を使う案と、テンプレートエンジンで決定的に生成する案がある。
また NFR-030 では「組版バッチが当日分の生成に失敗した場合の代替動作は未確定」とされていた。

## 決定

新聞の組版はテンプレートエンジン（静的なレイアウト定義）を使って決定的に生成する。
LLM による文章生成は行わない。
組版に失敗した場合は「休刊」として、その配達回は紙面を届けない（ADR-0035 で補足: 郵便受けには休刊の印と手紙が届き、新聞の通知も送る）。

（ADR-0035 で追加）新聞は、その便に手紙があるかにかかわらず全住民の郵便受けに届ける（07:00 / 17:00）。紙面は全住民に同じ。
休刊の回も、郵便受けには紙面の代わりに休刊の印が届き、新聞の通知「新聞が配達されました！」を送る（ADR-0035 の D11）。知り合いが少なくても成り立つ紙面の中身（住民ごとに変えるか・興味を集めるか・ニュースの出どころ・加工に LLM を使うか）は
OQ-051（要回答）で、答えが出るまでこの ADR のとおり掲示板の投稿からテンプレートで組む。

**紙面の構成（案）**

| 面 | 内容 |
|----|------|
| 1 面 | 掲示板の最新投稿（カテゴリ別） |
| 2 面 | 商店街・団体からのお知らせ（段階 3 以降） |
| 折込 | 住民募集・イベント募集投稿 |

## 理由

- LLM を使わないことで冪等性（FR-037）を保証しやすい（同じ入力 → 同じ出力）
- 組版失敗時に「休刊」とすることで、途中まで生成した壊れた紙面を届けるリスクを回避
- テンプレートは開発・テスト環境で LLM なし（NFR-063）でも動作する
- LLM による文章生成は幻覚リスクがあり、コンテンツポリシーとの整合が難しい

## 代わりの案

**LLM で記事を生成する**: 冪等性の保証が難しく、幻覚リスクもある。
また LLM の判断をコンテンツに組み込む形になり NFR-011 の精神と合わない。不採用。
**組版失敗時に前日の紙面を流用**: 古い情報を届けることになり、住民を誤解させる可能性がある。不採用。

## 影響

- 非同期処理: `async.md` で組版バッチの入力仕様・テンプレート形式・「休刊」ロジックを設計する
- アーキテクチャ: 組版エンジンの技術選定は別途 ADR に記録する
