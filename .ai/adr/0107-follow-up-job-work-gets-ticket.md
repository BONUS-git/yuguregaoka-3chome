# 0107 — 外待ちでもあとにジョブが作るものがあればチケット

- 状態: 置き換え（→ 0108）
- 日付: 2026-11-28

チケット YGO-088（G-080）による。仕分け 16 の K-020 のうち、gaps の冒頭の例外の決まり（どの行にチケットを切るか）だけを決める。K-020 の行ごとの案のうち G-081 の (a)・G-082 の (b)・G-083 の (d) は、この ADR では決めない。

## 背景

`.ai/gaps.md` の冒頭は、今の M に向かう行を、題に G-NNN を 1 つ付けたチケットで 1 行ずつ閉じると決めている。例外として、マスターの作業を待つだけの行（ジョブが作るもののない行）はチケットを切らず、gaps の表と準備書 `.ai/deploy/readiness.md` で追う `[assumed]`。
秘書の決まりも「外の作業を待つだけのことはチケットにせず、ジョブが作るものがあるときだけチケットを切る」としている。
一方、固定コードの点検（`check:consolidation`）は、M1 に向かう gaps の行のすべてにチケットを求める。G-080 は「外の作業を待つだけ」としてチケットを切らなかったため、点検で ✗ のまま残り、仕分け 13〜16 で同じ記録が続いた（R-072）。
ところが G-080 は、外の作業（秘書が実装のジョブにコマンドを許すこと）が済んだあとに、ジョブが作るものがある。一覧が動くのを確かめた事実を記録し、`environment.md` §5・準備書 §4・G-080 の行の「今の状態」を書き直すことである。

## 決定

- **D1 あとにジョブが作るものがあれば、外待ちの行でもチケットを切る**: gaps の行が外の作業（マスターや秘書の作業）を待っていても、それが済んだあとにジョブが作るもの（確かめた事実の記録、文書の今の状態の書き直し、ADR の置き換え、コード）があれば、冒頭の例外に当たらない。その行には、題に G-NNN を 1 つ付けたチケットを切る。チケットの依存の節には、待つ外の作業と「それが済むまで実装の変更は出さない」ことを書く。
- **D2 例外は、ジョブが作るものが何もない行に限る**: チケットを切らずに gaps の表と準備書で追うのは、外の作業が済めば閉じる条件の事実がそろい、ジョブが何も作らない行だけとする。そのような行は、閉じる条件の事実がそろったら閉じる。

## 理由

- チケットは、ジョブが作るものを追うためのものである。外の作業を待つあいだも、あとで作るものがあるなら、チケットの依存の節で待ちを示せる。「待つだけ」とまとめると、待ったあとの仕事を追う場所がなくなる。
- D1 に従えば、ジョブが作るもののある行は固定コードの点検と秘書の決まりを両方満たす。点検の ✗ が毎回の仕分けに残らない。
- D2 の例外を残すのは、ジョブが作るもののないチケットが「待つ」だけの記録になり、秘書の決まり（待つだけのことはチケットにしない）に反するためである。

## 代わりの案（選ばなかった理由）

- **G-080 にはチケットを切らず、理由の列の頭に `外待ち:` の句を付ける（K-020 の案 (c)）**: 句で区別する点検は秘書の固定コードの変更が入るまで効かない。それまで G-080 は点検で ✗ のまま残る。また、待ったあとにジョブが作るもの（確かめた事実の記録と今の状態の書き直し）を追う場所がない。
- **外の作業を待つ行はすべてチケットにしない（今の冒頭の例外のまま）**: G-080 と同じ形の行が点検で ✗ のまま残り、仕分けが毎回同じ記録で止まる（R-072）。
- **外の作業を待つ行はすべてチケットにする**: ジョブが何も作らない行では、チケットが待つだけの記録になる。秘書の決まりに反する。

## 影響

- `.ai/gaps.md` の冒頭の例外の文を、この ADR の D1・D2 にそろえる。G-080 の行は D1 により YGO-088 で追う。
- G-082 の行は、D1 に照らすと、外の作業が済んだあとにジョブが作るもの（YGO-078 の出し直しの変更）がある。そのため冒頭の例外に当たらない。この行にどのチケットを置くか（K-020 の案 (b) で G-080 にまとめるか、題に G-082 を付けたチケットを切るか）は K-020 の残りで決める。
- G-081・G-083 の扱い（K-020 の案 (a)・(d)）は、この ADR では変えない。
