# 0003 — 住所録には相手の新しい住所を自動で表示しない

- 状態: 採用
- 日付: 2026-11-19

## 背景

住民が引っ越した後、旧住所での住所録登録がある場合、自動的に新住所へ更新する設計案がある（FR-057）。
一方で、DV 等の事情で相手に気づかれないように引っ越す住民がいる可能性がある。
「住所をユーザー ID にした街」というコンセプトは、住所変更が社会的に意味を持つことを示唆している。

## 決定

住所録に登録された住民が引っ越しても、住所録の住所を自動更新しない。
旧住所に届いた手紙は住所転送設定に従って新住所へ転送されるが（FR-005）、
住所録自体は住民が手動で更新するまで旧住所のままとする。

## 理由

- 避けたい相手から逃れた住民の新住所を、その相手の住所録へ自動で通知しない
- 「引っ越しは意味を持つ行為」というプロダクトコンセプトに沿っている
- 手動更新の手間は、プロダクトのアナログな手触り感とも一致する

## 代わりの案

**相手が引っ越したら住所録を自動更新**: 相手の新住所が意図せず知られる危険があるため不採用。
**住所変更を通知して相手が更新を選択する方式**: プライバシー保護の観点からは許容できるが、
実装コストに対して既存の手動更新と実質的に同じになるため採用しない。

## 影響

- DB 設計: 住所録テーブルは相手の内部 ID ではなく、登録時点の住所文字列を保持する
- API 設計: 住所録更新 API は住民が明示的に呼び出す必要がある
