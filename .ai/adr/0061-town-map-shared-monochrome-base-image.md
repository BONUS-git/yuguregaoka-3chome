# 0061 — 地図は全住民で共有する 1 枚の白黒の画像

- 状態: 採用
- 日付: 2026-11-21

ADR-0037 を丸ごと置き換える。ADR-0037 の決定（D1〜D5）を、ADR-0063（地図のための API は入居の一覧だけ）と ADR-0064（印と入居の層）に合わせて今の状態に書き直し、同じ番号でこの ADR に移した。
書き直したのは D1 と D3。D2・D4・D5 は ADR-0037 と同じ。

## 背景

OQ-005 の答え（ADR-0063）で、架空の街の地図は 1 枚の静的な画像として MVP（M1）で作ると決まった。
OQ-044 で、住民が自分の住所の場所を地図で見られるものかをマスターに聞き、2026-11-19 に次のとおり答えがあった（原文）。

> 全ユーザーで共有して、知り合いの家には印ができるようなものが理想。ほんとはゲーム風にしたいが、現時点では１枚の画像。白黒の地図が今のイメージ

印（自分の家・登録のときの候補・知り合いの家）は OQ-054 の答え（2026-11-20）で付けることになり、空き家・入居の表示の範囲は OQ-079 の答え（2026-11-21）で決まった（どちらも ADR-0064）。
地図のための API は、OQ-079 の答えにより入居の一覧の 1 つだけを持つ（ADR-0063 の D3）。

## 決定

1. **D1 全住民で共有する 1 枚の画像**（OQ-044 の答えの「全ユーザーで共有して」「現時点では１枚の画像」より）:
   - (a) 地図は全住民で共有する 1 枚の画像（土台）とする。
   - (b) 土台の画像は住民ごとに中身を変えない（どの住民にも、ログインの前にもバイト単位で同じ画像を出す。ADR-0064 の D3）。印と入居の層は土台に描き込まず、C1 が土台の上に重ねる。住民ごとに変わるのは印の層だけ。
   ADR-0063 の D1 (a)（静的・拡大・移動・検索なし。押せるのは登録の画面の候補の印だけ）・D3（地図のための API は入居の一覧だけ。画像・位置・座標を返す API、DB の地図の表・ジオデータ・外部の地図サービスは持たない）・D4（土台に載せないもの）・D5（SVG を `<img>` で出す）に従う。
2. **D2 白黒**（OQ-044 の答えの「白黒の地図が今のイメージ」より）: 地図の画像は白黒で描く。
   秘書の読み方として、「白黒」は色相を持たないこと（白・黒と、その間の灰色だけ。sRGB で R=G=B の色）とする。
   画像の中のすべての色（`fill`・`stroke`・`stop-color` など）を、この範囲に限る（`roadmap.md` の A-16 (6)）。印と入居の層も同じ範囲で描く（ADR-0064 の D8）。
3. **D3 印と入居の層**: 自分の家・登録のときの候補・知り合いの家の印と、空き家・入居の層を、土台の上に重ねる。
   いつ・誰に・何を示すかは ADR-0064 の D1〜D18 に書く。住所と画像の上の位置の対応は、C1 の静的な配置の定義と計算で求める（ADR-0064 の D4）。位置・座標を返す API と DB の地図の表は持たない（ADR-0063 の D3）。
4. **D4 ゲーム風の地図は今は作らない**（OQ-044 の答えの「ほんとはゲーム風にしたいが、現時点では１枚の画像」より）:
   何を指すか・どの段階で作るかは決めず、OQ-055（持ち越し）にする。段階 2 の計画を立てる前にマスターに聞く。
5. **D5 要求の区分**: ADR-0024 の決定 5 に従い、FR-103 は `[inferred]`（マスターの答え OQ-005・OQ-044（2026-11-19）より）とする。

## 理由

- D1 (a) は、答えの「全ユーザーで共有して」「現時点では１枚の画像」による。D1 (b) は、印と入居の層を別の層にすれば土台を同じにでき、土台から住所や住民の有無が漏れないから（ADR-0064 の D3）。
- D1 で ADR-0063 の D3 に従うのは、入居の一覧の 1 つの経路のほかに、地図のための API・DB・ジオデータが要らないから。入居の一覧は住所と 2 値だけで、画像も位置も返さない。
- D2 は、答えの「白黒の地図が今のイメージ」による。灰色を含めるのは秘書の読み方で、白と黒の 2 色だけでは区画・道・地名の見分けが付きにくいから。R=G=B に限れば、画像のファイルを読む単体テストで機械的に確かめられる。
- D3 は、印と入居の表示を土台を変えずに出すため。
- D4 は、今の段階（MVP）に要らないので持ち越しにする。

## 代わりの案（選ばなかった理由）

- **白と黒の 2 色だけに限る**: 区画と道・地名の見分けが付きにくい。答えの「白黒」は、灰色を除くとまでは書いていない。
- **色を限らない（白黒は目安とする）**: 答えの「白黒の地図」と食い違い、受け入れ確認で確かめられない。
- **住民ごとに印を描き込んだ土台を出す**: 全住民で共有する画像（D1 (a)）と食い違う（ADR-0064 の代わりの案）。
- **ゲーム風の地図の段階を今決める**: 答えに書かれていない（OQ-055）。

## 決めていないこと

- ゲーム風の地図が何を指すか・どの段階で作るか: OQ-055（持ち越し）。
- 空き家の印も押して選べるようにするか: OQ-089（要回答、ADR-0064 の D7）。候補の印を押して選ぶことは OQ-080 → 決定（2026-11-21、ADR-0064 の D7）。
- 代替テキストとアクセシビリティの水準: OQ-033（持ち越し）。白黒の濃淡の差（コントラスト）は、その水準に合わせる。
