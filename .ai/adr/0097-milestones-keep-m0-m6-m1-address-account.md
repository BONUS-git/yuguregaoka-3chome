# 0097 — M は M0〜M6 のまま、M1 は住所・アカウント

- 状態: 採用
- 日付: 2026-11-26

`reviews/0002-phase-evaluation-2026-11-25.md` の R-054、`triage.md` 仕分け 4 の K-017（YGO-035）。
すべて秘書の判断 `[assumed]` で、新しい要回答はない。
この ADR は、ADR-0022 の決定（D2 の M0〜M6 の分け方、D3 の M3 の休刊だけの経路を含む）のどれも変えない。そのため ADR-0022 は置き換えず、状態は `採用` のまま。
この ADR が決めるのは、R-054 の「M1 が中心の体験に届かない」に対して M を分け直さないことと、手紙の一続きと中心の体験の全体がどの M の終わりで通るかだけ。
中心の体験の定義は `mvp.md` (a)（郵便受け・朝夕の定時配達・朝刊と夕刊・町内掲示板を含む 5 つの要素）のままで、この ADR は定義し直さない。

## 背景

R-054 は、M1（住所・アカウント）が中心の体験に届かず、MVP が大きいと指摘した。
K-017 は、M1 を作り始めてから M の分け方を変えると `roadmap.md` の M1・`mvp.md`・M1 の FR と受け入れ・図をそろえ直す出戻りが大きいので、今決めるとした。

## 決定

### D1 M は M0〜M6 のまま、M1 の FR は変えない

M は ADR-0022 の D2 のとおり M0〜M6 の 7 つのまま。M1 は住所・アカウント（F-01・F-02・F-19）のままで、`roadmap.md` §4 の `- M1:` の行の 18 の FR（`mvp.md` (b) の FR 列と同じ）は変えない `[assumed]`。

### D2 手紙の一続きは M3、中心の体験の全体は M5 の終わりで通る

登録から手紙が郵便受けに届くまでの一続き（登録 → 互いに住所録に入れる → 手紙の投函 → 定時配達 → 郵便受け）は M1 → M2 → M3 で作り、M3 の終わりで通る。M1 で登録とログイン、M2 で住所録と手紙の投函、M3 で定時配達と郵便受けができる `[assumed]`。
M3 は M4（町内掲示板とモデレーション）と M5（朝刊・夕刊の組版）を待たない。ADR-0022 の D3 のとおり、M3 は J3 の休刊だけの経路を通り、J2 を積まない。
中心の体験の全体（`mvp.md` (a) の 5 つの要素。町内掲示板は M4、朝刊・夕刊は M5）がそろうのは M5 の終わり。

### D3 配達と郵便受けの一続きは M2・M3 を今の M にしたときに確かめる

配達と郵便受けの一続きの整合（FR・受け入れ・図）は、M2・M3 が今の M になったときに、その M の設計の見直しで確かめる `[assumed]`。
M2・M3 の中で手紙の一続きに要るものを先に作る順は `gaps.md` G-069（M2）で扱う。各 M の FR は変えない。

## 採らなかった案

- (a) M1 を広げ、住所録・手紙・配達・郵便受けの一部を M1 に入れる: 手紙の一続きが通る位置（配達と郵便受けができるところ）は変わらず、確かめる位置が動くだけ。確かめ済みの M1（図 5 つ・地図・A-12・A-16・A-18）と、マスターが確かめた `mvp.md` をそろえ直す出戻りが起き、K-017 が避けたい出戻りそのものになる。
- (b) M2 と M3 を組み直す（手紙と配達を 1 つの M にまとめる、など）: 手紙の一続きが通る位置は M3 の終わりと同じで、M の番号と受け入れ（A-NN）・ADR の参照を付け直す手間だけが増える。M の中の作る順（G-069）で同じ効果が得られる。

## 結果

- `roadmap.md` §4 の段階の文に、この ADR と、手紙の一続きが M3 の終わりで通り、中心の体験の全体が M5 の終わりでそろうことを書く。表・`- M1:` の行・受け入れ条件は変わらない。
- R-054 の主な論点（各段階が M1 の中の整合だけを確かめる）は、秘書の段階の定義の側のことで、レポジトリの M を分け直しても直らない（YGO-028 の記録と同じ）。
