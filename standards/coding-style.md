# Coding Style Standard

## Core Principles

- Prefer consistency over cleverness.
- Follow existing patterns in the codebase before introducing new ones.
- Modify the minimum required files.
- Keep changes cohesive.

---

## Naming

- Names should reveal intent.
- Avoid abbreviations unless they are universally understood in the domain.

---

## Comments

Write comments only when the **why** is non-obvious.

Do not describe what the code does — well-named identifiers already do that.
